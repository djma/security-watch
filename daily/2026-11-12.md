Covers about 24–36 hours up to 08:00 Asia/Shanghai. Checked the cve.now feeds (exploited, critical, Redis/PostgreSQL, Rust crates), CISA's exploited-bugs list (KEV), Chrome and Node.js release notes, RustSec, the PostgreSQL release schedule, Bitcoin Core advisories and X. Nothing new for ClickHouse, Redis or Bun.

## Servers & dev tools

- **Node.js security releases are out: 22.23.5, 24.22.3 and 26.13.1 (seven HIGH issues).** Worst: CVE-2026-123864, where an unauthenticated client can make an HTTPS server leak heap memory from other connections, including TLS private keys (needs a handler that calls `res.flushHeaders()` before the body ends; plain `node:http` not affected). Also HTTP/2 remote crash (CVE-2026-123863) and HTTP/2 memory/FD leak (CVE-2026-123865), plus llhttp, undici and sqlite updates. Not known exploited. **Do:** upgrade Node hosts and rebuild Node-based images now; if you ran an exposed HTTPS Node server with that handler pattern, consider rotating its TLS key. EOL lines (20.x, 25.x and older) get no fix. [Node.js advisory](https://nodejs.org/en/blog/vulnerability/november-2026-security-releases)

- **Malicious crate `lwd-uri-util` pulled from crates.io (RUSTSEC-2026-0483).** Eight versions were published Nov 9 and live ~12 hours; building any crate that uses it stole SSH keys, AWS credentials and other secrets. RustSec found no evidence of real use. **Do:** `grep lwd-uri-util` your `Cargo.lock` files (and CI caches); if present, treat that machine as compromised: rebuild it and rotate SSH keys, cloud credentials and tokens it held. [RustSec](https://rustsec.org/advisories/RUSTSEC-2026-0483.html)

- **CISA's deadline for OpenSSH *sshole (CVE-2026-123158) is today, and scanners may miss it.** Exploitation continues against musl builds without PAM (Alpine, slim containers). Per a post on X, Alpine's security database lists the fix only for edge so far, so Trivy/Grype may not flag Alpine 3.21–3.24 images. **Do:** check directly (`apk info -v openssh-server`, `ldd $(command -v sshd) | grep musl`), move to OpenSSH **10.6p2** or a fixed distro build, restart sshd, set `PasswordAuthentication no`. [CISA KEV](https://www.cisa.gov/known-exploited-vulnerabilities-catalog) · [scanner note on X](https://x.com/changeswatch/status/2120536312725799289)

- **cap-std sandbox escape: paths ending in `/` follow symlinks out of the sandbox (RUSTSEC-2026-0482, CVSS 9.0).** Affects `cap-primitives` (under `cap-std` and crates built on it, e.g. WASI hosts). Not known exploited. **Do:** `cargo update -p cap-primitives` to **3.4.6+ (3.x) or 4.0.3+**. [RustSec](https://rustsec.org/advisories/RUSTSEC-2026-0482.html)

- **Update: five more Hickory DNS advisories (RUSTSEC-2026-0487 to -0491), same fix.** Panics on malformed zone-file text and TSIG records, and memory blow-up from fake record counts in DNS headers (affects anything decoding untrusted DNS). All fixed in **hickory-proto 0.26.2**, the version from earlier digests. **Do:** if not done, `cargo update -p hickory-proto -p hickory-resolver`. [RustSec](https://rustsec.org/advisories/RUSTSEC-2026-0491.html)

- **PostgreSQL minor releases with security fixes (CVE-2026-6460) are expected today, Thu Nov 12; last release for PostgreSQL 14.** Not yet posted at time of writing. **Do:** apply the minor upgrade as soon as packages land; plan off 14. [PostgreSQL roadmap](https://www.postgresql.org/developer/roadmap/)

- **Minor:** `rustix` xattr functions are unsound with zero-length buffers (RUSTSEC-2026-0486), fixed in **1.1.6**. Rails Active Storage file write/read with ImageMagick (CVE-2026-126082), fixed in **8.1.4.1 / 8.0.5.2**. [RustSec](https://rustsec.org/advisories/RUSTSEC-2026-0486.html) · [cve.now](https://cve.now/CVE-2026-126082)

## Devices & accounts

- **Telegram for Android: remote code execution via the new message widgets, fixed Nov 11.** Researchers showed RCE a day after Bot API 10.4 widgets launched; per X reports, Telegram fixed it Nov 11 and is rolling it out. Widgets currently appear in private bot chats. **Do:** update Telegram on Android now and avoid interacting with widgets from bots you don't know. [X story](https://x.com/i/trending/2120542573999849929)

- **Chrome Extended Stable 156.0.8078.100 (72 security fixes) and ChromeOS LTS-150 update.** For people on the slower Extended channel; regular Stable users should already be on 157.0.8103.50+ for the exploited zero-day from yesterday. Chrome for Android 157.0.8103.78 is a stability release. **Do:** update and relaunch. [Chrome Releases](https://chromereleases.googleblog.com/)

## Crypto & scams

- **Bitcoin Core disclosed three already-patched bugs.** The high-severity one (CVE-2025-62861) can stop mining nodes from building block templates after a reorg until restart (per X, versions 28.0–28.2 and 29.0–29.1); the others weaken Tor-peer protections and can stall block processing. **Do:** if you run a node, make sure it's on a current supported release. [Bitcoin Core advisories](https://bitcoincore.org/en/security-advisories/)

- **Dormant-wallet address poisoning is fast.** A 2015-era wallet's 0.05 ETH test send drew lookalike-address spam within three minutes. **Do:** never copy a destination from transaction history; verify the full address from the source. [X story](https://x.com/i/trending/2120115521924530584)
