# Security digest — 2026-11-10
Covers about 24–36 hours up to 08:00 Asia/Shanghai. Checked the cve.now feeds (exploited, critical, Redis/PostgreSQL, Rust crates), CISA's exploited-bugs list (KEV), Apple's security releases, vendor advisories and X. Nothing new for ClickHouse, Redis, PostgreSQL or Bun beyond earlier digests.

## Servers & dev tools

- **Update: OpenSSH *sshole (CVE-2026-123158) is now on CISA's exploited list (Nov 9).** Public exploit code exists, GreyNoise reports a first successful exploit on Nov 7, and honeypot hits keep rising. Only musl builds without PAM (Alpine, OpenWrt, many slim containers) are affected; glibc distros like Debian, Ubuntu and RHEL are not. **Do:** upgrade to **OpenSSH 10.6p2** or your distro's fixed package (Alpine: `apk upgrade -U -a`), restart sshd, and set `PasswordAuthentication no`; then check auth logs for password logins on accounts that should be key-only. [cve.now](https://cve.now/CVE-2026-123158) · [OpenSSH 10.6p2](https://www.openssh.com/txt/release-10.6p2) · [cve.now on X](https://x.com/cvedotnow/status/2119830267082789202)

- **Hijacked npm package: `@ethersphere/bee-js` 13.3.0 (and Swarm Desktop 0.56.2) shipped a wallet stealer and backdoor.** Attackers used stolen CI credentials to publish releases with valid npm provenance and Apple notarization; the payload runs from a postinstall script, so installing was enough even without importing it, and `create-swarm-app` pulled it in too. Both releases are withdrawn. **Do:** search lockfiles and CI logs for `bee-js@13.3.0`; pin **13.2.0** and use Swarm Desktop **0.56.3** (or roll back to 0.56.1). If it installed anywhere, treat that machine or runner as compromised: rebuild it, rotate its secrets from a clean device, and move any wallet funds it could reach. [The Hacker News on X](https://x.com/TheHackersNews/status/2119846770591363472) · [Advisory MAL-2026-18773 on X](https://x.com/latent_node/status/2119675294005215597)

- **Reminder: CISA's deadline for the exploited Brotli bug (CVE-2026-111497) is today, Nov 10.** The out-of-bounds write sits in the Brotli decoder bundled by Node, Bun, Python and others; Apple also patched it in this week's updates. **Do:** run Bun **1.4.4 or later**, update Node/Python images that bundle Brotli (fixed upstream in **Brotli 1.2.1**), and redeploy. [cve.now](https://cve.now/CVE-2026-111497)

- **rustls: four more CVEs published, all fixed in 0.23.46.** They cover a key-exchange downgrade via an unauthenticated ServerHello (CVE-2026-123611), memory exhaustion via Brotli certificate decompression (CVE-2026-123610), secret key material printed by `Debug` formatting (CVE-2026-123609) and a TLS 1.3 encryption-level check (CVE-2026-123613). No known exploitation. **Do:** if you haven't already, `cargo update -p rustls` to **0.23.46** or later. [cve.now](https://cve.now/CVE-2026-123611) · [rustls advisories](https://github.com/rustls/rustls/security/advisories)

- **rmcp (Rust MCP SDK): several advisories.** A malicious MCP server can crash clients with an endless response body (RUSTSEC-2026-0462) or make the OAuth client send requests to internal or cloud-metadata addresses (RUSTSEC-2026-0457, GHSA-C9XM-49CP-XCR9); any client can exhaust memory on servers using the Streamable HTTP transport (RUSTSEC-2026-0461). **Do:** update `rmcp` to the latest release (`cargo update -p rmcp`) and check `cargo audit`. [cve.now](https://cve.now/RUSTSEC-2026-0462) · [cve.now SSRF advisory](https://cve.now/RUSTSEC-2026-0457)

- **aws-lc-sys X.509 name-constraints bypass (RUSTSEC-2026-0044).** Certificates with wildcard or raw-Unicode Common Names can slip past name constraints. Affects Rust apps using AWS-LC (including rustls's default `aws-lc-rs` backend) only when CN fallback applies. **Do:** update `aws-lc-sys`/`aws-lc-rs` to the latest release; run `cargo audit` to confirm. [cve.now](https://cve.now/RUSTSEC-2026-0044)

- **Unauthenticated Redis queues can mean RCE: rConfig CVE-2026-124079 (CVSS 9.3).** rConfig's Laravel Horizon queue sat on a Redis with no password and unserialized jobs, so anyone who could write to Redis ran code, often as root. **Do:** if you run rConfig, update to **Core 8.2.19 / Pro 8.4.1** and rotate stored device and API credentials. More generally, never expose a Redis used for job queues without a password and firewalling. [cve.now on X](https://x.com/cvedotnow/status/2119772889993949543)

## Devices & accounts

- **Apple shipped iOS 27.2.1, iOS 26.7.3, iOS 18.7.12, macOS 27.2.1 / 26.7.3 / 15.8.3 and watchOS/visionOS updates (Nov 9).** Fixes include a bug letting a remote attacker join an iMessage group chat and read it, Bluetooth pairing without user interaction, Bluetooth memory corruption, and the exploited Brotli bug. Apple doesn't say any of these were exploited. Separately, a public iOS 26/27 sandbox-escape exploit ("worse_query") was released on Nov 8, and it isn't confirmed whether these updates fix it. **Do:** update iPhone, iPad, Mac and Watch now; if you're still on iOS 18.4–18.7.x with crypto wallets, this also closes out the DarkSword wallet-stealer risk from Nov 8. [Apple security releases](https://support.apple.com/en-us/100100) · [iOS 27.2.1 notes](https://support.apple.com/en-us/149715)

## Crypto & scams

- **Update: LNbits patches: confirm before restarting.** LNbits' own X account hasn't named a fixed version since its Nov 8 stop-everything alert (it said the hosted service would resume within about 24 hours), though some trackers report fixes starting to land. **Do:** keep self-hosted LNbits stopped and Paywall disabled until LNbits' [GitHub releases](https://github.com/lnbits/lnbits/releases) or [@lnbits](https://x.com/lnbits/status/2119428804951048237) name a patched version; after restarting, review recent accounts and withdrawals. Ignore "support" DMs.

- **Ankr's ankrETH bridge was drained of about $300K with forged cross-chain receipts (Nov 9).** The bridge reportedly stayed unpaused afterward. **Do:** don't use the Ankr bridge contracts until Ankr posts an all-clear. [X story](https://x.com/i/trending/2119728279850832346)

- **Fake-recruiter npm malware keeps going.** JFrog traced a poisoned npm package to a full fake company (careers site, verified-looking LinkedIn recruiters) handing out malware, the same fake-interview playbook tied to the October Binance theft. **Do:** never run a "take-home test" repo or `npm install` from a recruiter on your main machine; use a throwaway VM. [DFIR Radar on X](https://x.com/DFIR_Radar/status/2119883396281409628)
