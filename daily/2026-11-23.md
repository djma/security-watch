## Servers & dev tools

- **MONAI Label CVE-2026-133968 (9.8): used as a zero-day by autonomous "Cairn" AI agents, and public exploit code is now out.** AWS says a China-linked actor gave Cairn agents a target list and the goal "get a shell". The agents found a path traversal in `PUT /datastore/image` / `/datastore/label` and got from mapping the API to root on a university server in about 11 minutes. A PoC appeared on GitHub on Nov 21. **Do:** upgrade MONAI Label to **0.8.6**, turn on auth, and don't expose it to the internet. More generally, assume any internet-facing service without auth (databases, caches, AI/ML servers) will now be probed by automated agents: keep them behind a firewall or VPN and require passwords. [AWS Security Blog](https://aws.amazon.com/blogs/security/chinese-nexus-actors-cairn-ai-agents-found-a-zero-day-on-their-own/) · [GHSA-qc22-rmgc-vg94](https://github.com/Project-MONAI/MONAILabel/security/advisories/GHSA-qc22-rmgc-vg94) · [cve.now](https://cve.now/CVE-2026-133968)

- **Together AI: an outsider downloaded stored samples of customer prompts (disclosed Nov 21).** An AI coding agent committed a credential for a private Hugging Face repo to a public GitHub repo. Someone used it to download prompt samples from serverless requests to **MiniMax M3, GLM-5.2 and Kimi K2.6**, mostly from June 24 and July 4, 8 and 14, 2026. Together is still reviewing the data and will notify affected customers. This comes after yesterday's OpenRouter/MiniMax notice. **Do:** if you sent those models prompts through Together in June or July, rotate any key, password or token that was in a prompt or tool output, and watch for Together's email. [Together AI notice](https://www.together.ai/blog/security-event-prompt-leakage-for-requests-in-june-and-july-of-2026)

- **simple-git CVE-2026-134815 (9.2): command execution through argument injection in `listRemote()` / `raw()`.** An attacker who controls arguments can inject `--exec` and run commands on the host. Every simple-git download last week (15.3M) was a vulnerable version. Not known exploited. **Do:** update to **simple-git 4.1.0** (and **@simple-git/argv-parser 3.0.0**), especially in tools or servers that pass user-supplied repo URLs or refs. [cve.now](https://cve.now/CVE-2026-134815) · [X: @cvedotnow](https://x.com/cvedotnow/status/2124629605722034249)

- **Minor (not known exploited):**

[X: @cvedotnow](https://x.com/cvedotnow/status/2124468022911856859)
  - **binary-parser CVE-2026-134814 (9.2):** code injection if an attacker controls parser definitions. Fix: **2.3.1**. [cve.now](https://cve.now/CVE-2026-134814)
  - **Weblate CVE-2026-134838 (9.1):** account takeover through password reset with a case-folded lookalike email. Self-hosters should update to **2026.11**. [X: @cvedotnow](https://x.com/cvedotnow/status/2124632114142286151)
  - **Malicious packages flagged in the last 24h** include npm `cti-defense`, `@leadstack/crm-connect`, `autoloan`, `@c1-ease/core` and PyPI `solblock`. If one is in a lockfile, remove it and rotate every secret that machine could read. [X: @infrastack_ai](https://x.com/infrastack_ai/status/2124639108039647245)

## Devices & accounts

- **WhatsApp for Android: update to 2.26.35.74 or later.** CVE-2026-102769: a crafted "order details" message from an unofficial client could, when tapped, delete locally stored WhatsApp files and leak one bit of chat-database info. Not exploited. WhatsApp's advisory page also lists CVE-2026-23871 (fixed in 2.26.17.4), where a crafted Click-to-WhatsApp ad reply could reveal your IP address. WhatsApp says that one "may have been abused" together with spam messages. [WhatsApp advisories](https://www.whatsapp.com/security/advisories/2026)
- **Reminder:** CISA's deadline for the exploited Outlook hash-leak bug (CVE-2026-124194) is Nov 24. If Office hasn't installed the Nov 10 update, do it now. No new Chrome, Apple or Android patches today. [X: summary](https://x.com/emits_ca/status/2124571051883385269)

## Crypto & scams

- **Chainflip's losses are now about $12M, not $4.86M.** Besides the Ethereum vault, about **122.86 BTC** was taken, which points to a compromised validator signing key. Chainflip is offering a 10% bounty if 90% is returned by Nov 23, and the protocol stays in safe mode. **Do:** use only official Chainflip channels, and ignore "refund" or "claim" links. [The Block](https://www.theblock.co/news/defi/2026-11-22-chainflips-losses-climb-to-12-million-after-protocol-discloses-122-9-btc-theft-offers-hacker-bounty-444829)
- **Fusionist ACE bridge (BNB Chain) exploited Nov 22.** A privileged bridge minter printed unbacked ACE and sold it (initial reports said ~$1.04M, later ~$2M), and traders then drained a further ~$3.7M. Fusionist says to stop all ACE trading, transfers and BSC bridging. **Do:** don't buy the dip, revoke ACE approvals, and ignore "refund" DMs. [The Defiant](https://thedefiant.io/news/hacks/fusionist-urges-ace-trading-pause-after-exploit-alert) · [X: CoinLab](https://x.com/CoinLab_news/status/2124645631344152774)
- **Fake OpenSea copies of free-mint pages are circulating.** Mint only from links on the project's verified accounts, and never sign a "setApprovalForAll" for a free mint. [X: scam roundup](https://x.com/BullDuck/status/2124428901862473881)
