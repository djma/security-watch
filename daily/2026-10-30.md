# Security digest — 2026-10-30
Covers about 48 hours up to 16:00 Asia/Shanghai. Only the Chrome and Apple items were checked against official sources. The rest are reports from X that haven't been confirmed. CISA's exploited-bugs list (KEV), Microsoft and Android weren't checked.

- **Fake Claude Code VS Code extension (Open VSX, v2.1.313) adds a backdoor.** It adds an `svc-telemetry` key to `~/.ssh/authorized_keys` and connects out to 134.209.82.225:8099. Reported as being used in attacks now. **Do:** remove any SSH key you don't recognize, then rebuild the environment and change the SSH keys and tokens on it. [X](https://x.com/i/trending/2116054158553842030)
- **Chrome 156 fixes 21 security bugs, 1 critical.** None reported as exploited. **Do:** update to 156.0.8078.79 or later and restart. [Chrome Releases](https://chromereleases.googleblog.com/)
- **Apple 27.2 updates** for iOS, iPadOS, macOS, Safari and watchOS. Older devices get iOS 26.7.2 or 18.7.11, or macOS 26.7.2 or 15.8.2. Mac command-line tools reportedly still trust eMudhra certificates that Apple blocked elsewhere. **Do:** update all devices. [Apple](https://support.apple.com/en-us/100100) · [X](https://x.com/i/trending/2115534855199244699)
- **Crypto scams.** Fake Trust Wallet "card" sites drain wallets you connect. A tampered third-party script on Polymarket led to about $2.5M stolen. **Do:** don't connect your wallet to perk offers, and revoke old token approvals. [X](https://x.com/i/trending/2115338252378931313) · [X](https://x.com/i/trending/2115867041815289909)
- **Tampered Ledger wallets sold in Singapore shops** stole recovery phrases. **Do:** buy only from the maker, and never use a recovery phrase that came in the box. [X](https://x.com/i/trending/2115717341136765410)
- **Binance theft (unconfirmed) and exchange data leaks** at a Coinbase vendor, Bithumb and Korean brokers. **Do:** expect phishing and SIM-swap attempts, use a security key instead of SMS codes, and turn on withdrawal address whitelists. [X](https://x.com/i/trending/2116063292150218854) · [X](https://x.com/i/trending/2115262479601484050)
- **Servers:** a reported Linux kernel TCP flaw, CVE-2026-98432, and exploited PHP and Node.js bugs (fixed in PHP 8.5.12 or 8.4.27, and Node 22.23.4, 24.22.1 or 26.12.1). **Do:** patch and reboot. [X](https://x.com/i/trending/2115800593377734763) · [X](https://x.com/i/trending/2115122008426176782)
