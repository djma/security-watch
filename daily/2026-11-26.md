## Servers & dev tools

- **psqlODBC (the PostgreSQL ODBC driver): 17 CVEs published Nov 25, fixed in 18.00.0007.** The worst, CVE-2026-136500 (8.1), lets a user who controls one bound parameter or a catalog-function name run SQL as the app's database role. It only applies to non-UTF-8 ANSI connections (BIG5 aliases, JOHAB, EUC_TW/CN/KR) where the driver substitutes parameters itself. Other fixes cover an `sslmode` parsing bug that can leave connections unencrypted (CVE-2026-136511), the password showing up in debug logs (CVE-2026-136504), and connection-string injection (CVE-2026-136507). None is known exploited. **Do:** update psqlODBC to **18.00.0007** wherever an app or BI tool connects to Postgres over ODBC. Check from the app's own session that TLS is actually on, and turn off driver debug logging. libpq, JDBC and native drivers aren't affected. [CVE-2026-136500](https://www.cve.org/CVERecord?id=CVE-2026-136500) · [psqlODBC changelog](https://odbc.postgresql.org/changelog/) · [X: @cvedotnow](https://x.com/cvedotnow/status/2125729346497175874)
- **Xen Orchestra CVE-2026-133469: REST API login bypass, exploited and added to CISA KEV Nov 25.** A crafted `authenticationToken` cookie logs the attacker in as the owner of an existing token, and from there they can list reusable login tokens. **Do:** update to **6.9.2 (stable) / 6.10.1 (latest)** (xo-server 5.211.2 / 5.213.1). From-source installs: pull latest master. Keep the XO web UI off the internet, and revoke existing authentication tokens after you patch. [CVE record](https://www.cve.org/cverecord?id=CVE-2026-133469) · [cve.now](https://cve.now/CVE-2026-133469)
- **Malicious npm `web3-mev-error-decoder` (11,218 downloads in its last week):** the npm package looked clean, but on install it pulled and ran a malicious payload from GitHub. It targets crypto developers. **Do:** search your lockfiles. If it was installed, treat the machine as compromised and move any keys or wallets that were on it. [Endor Labs](https://www.endorlabs.com/learn/web3-mev-error-decoder-a-clean-npm-package-that-installs-malicious-payload-from-github)
- **More malicious packages flagged Nov 25:** npm `git-crt-creator` (1.0.2, 1.0.3, 10.13.0) and `git-iss-creator` (10.13.0). PyPI MCP-themed `mcp-runtime-report`, `mcp-env-report`, `mcp-sysinfo-tools` (1.0.0) and `mcp-diag-7f3a` (1.0.0–1.2.0). **Do:** remove them and rotate credentials from any machine or CI runner that installed one. [X: infrastack](https://x.com/infrastack_ai/status/2125641526390952232) · [X: infrastack (PyPI)](https://x.com/infrastack_ai/status/2125681197833674889)

## Devices & accounts

- **1Password backend breach (disclosed Nov 25).** Starting on or before Nov 19, an attacker used an employee's corporate GitHub account to push malicious code to backend services. They took names, emails, account IDs, sign-in times, SRP parameters and **tokens from invitation, provisioning and account-recovery emails** for a subset of users, and copied private source code and reached CI/CD. 1Password says vaults, Secret Keys, recovery keys, and the apps and browser extensions weren't affected. It has also lengthened the email codes from 6 digits to 10 characters. **Do:** you don't need to change anything in your account, but expect convincing phishing that uses your real name and email. Ignore unexpected 1Password invite or recovery emails, texts or calls. Only enter your password and Secret Key in the app or on a 1password.com address you typed yourself. [1Password](https://1password.com/blog/update-on-nov-2026-security-incident) · [BleepingComputer](https://www.bleepingcomputer.com/news/security/1password-customer-data-stolen-after-employee-github-account-breach/)

- **D-Link R32 router CVE-2026-136821 (9.4):** OS command injection in its DHMAPI handler. **Do:** check D-Link's support page for firmware, and turn off remote management. [X: @cvedotnow](https://x.com/cvedotnow/status/2125699150150881699)

## Crypto & scams

- **Fake Ledger letters by post:** personalized letters naming your device model (Nano S/S Plus/X) claim it was tampered with and send you to a QR-code "migration" that steals your seed. **Do:** Ledger never contacts customers by letter. Never scan the code or type your 24 words anywhere. If you did, move your funds to a new seed right away. [Ledger: physical mail phishing](https://support.ledger.com/article/physical-mail-phishing-scam)
- **Bitcoin hashrate hijacking via BGP (Nov 20):** a forged route for part of Braiins Pool's address space sent miners using unauthenticated **Stratum V1** to an impostor server (1,050–1,600 sites, up to 1.9 EH/s, 6–49 minutes per episode). **Do:** if you mine, switch to Stratum V2 or TLS stratum endpoints, and watch pool payouts against your hashrate. [Decrypt](https://decrypt.co/383999/another-bitcoin-mining-firm-hashrate-hijacking-attacks) · [Bitcoin.com](https://news.bitcoin.com/security/braiins-warns-of-widespread-bitcoin-hashrate-hijacking-attacks/)
- **ClickFix fake CAPTCHA wallet stealer:** a "verify you're human" page copies a PowerShell command to your clipboard that installs a crypto-wallet stealer. **Do:** never paste commands from a web page into Run, Terminal or PowerShell. [X: Malwarehunterr](https://x.com/Malwarehunterr/status/2125680250990506196)
- **Still live:** COLDCARD weak-seed migration and the Bullpen key-import drains ([2026-11-25](https://djma.github.io/security-watch/daily/2026-11-25.md)), Pump.fun's private-key import before Nov 30, and MoldyRoost iPhone ads ([2026-11-24](https://djma.github.io/security-watch/daily/2026-11-24.md)).
