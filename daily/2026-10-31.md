# Security digest — 2026-10-31
Covers about 24 hours up to 08:00 Asia/Shanghai. Checked CISA's exploited-bugs list (KEV), the cve.now feeds and X. Microsoft and Android bulletins had nothing new to check (Android's November bulletin isn't out yet), and Chrome's release feed didn't load; yesterday's Chrome 156 advice still stands.

- **Binance confirms a hack of its hot wallets (about $6.3B per CZ).** Binance has posted official incident updates and says user losses will be covered. Fake "refund" and "compensation" links are already circulating on X. **Do:** ignore any refund link, DM, email or call; check status only in the Binance app or at binance.com; never type in your recovery phrase or 2FA codes. [Binance update #2](https://x.com/binance/status/2116258356109496479) · [CZ](https://x.com/cz_binance/status/2116198836729520420)
- **Tampered Trezor Safe 5 found, sold by former reseller CryptoBilis (Indonesia, via Tokopedia).** A hidden board could capture the recovery phrase. Trezor says there are no confirmed cases from other sellers and no funds lost so far. **Do:** if you bought any Trezor from CryptoBilis since March 2026, make a new wallet with a fresh recovery phrase and move your funds. Otherwise nothing to do. [Trezor](https://x.com/Trezor/status/2116203376421519720) · [X](https://x.com/i/trending/2116072545044820401)
- **Apple kernel bug CVE-2025-43520 now has public exploit code.** It was already on CISA's exploited list. A malicious app could write to kernel memory. **Do:** make sure every iPhone, iPad and Mac is at least on iOS/iPadOS 26.1 or 18.7.2, or macOS 26.1, 15.7.2 or 14.8.2 (ideally the current 27.2). [cve.now](https://cve.now/CVE-2025-43520)
- **Update: public exploit code is out for the Linux kernel TCP bug CVE-2026-98432 (CVSS 9.8).** Not on CISA's exploited list yet. **Do:** update and reboot any Linux server, VPS or node to a fixed kernel (5.10.272, 5.15.223, 6.1.190, 6.6.159, 6.12.113 or later). If your distro's fix isn't out yet (Ubuntu was pending), disable Multipath TCP meanwhile. [cve.now](https://cve.now/CVE-2026-98432) · [@cvedotnow](https://x.com/cvedotnow/status/2116258989704978887)
- **Home routers:** new public exploit code for ASUS RT-AX55 (CVE-2023-39780) and the Realtek router SDK (CVE-2014-8361), both already exploited. **Do:** update router firmware, turn off remote admin and UPnP, and replace routers that no longer get updates. [cve.now ASUS](https://cve.now/CVE-2023-39780) · [cve.now Realtek](https://cve.now/CVE-2014-8361)
- **Applebee's app exposed customer data** through a hard-coded database password (researcher report via TechCrunch). **Do:** if you have an account, change the password and don't reuse it elsewhere. [@cvedotnow](https://x.com/cvedotnow/status/2116286638238142805)
- **Dev tools:** the moling MCP server (CVE-2026-62863) lets any website you visit run commands on your machine; fixed in 0.5.0. Laravel's TokenGuard auth bypass (CVE-2026-114509) has a public exploit; fixed in 12.68.0 and 13.29.0. **Do:** update if you use either. [@cvedotnow moling](https://x.com/cvedotnow/status/2116286685608628648) · [@cvedotnow Laravel](https://x.com/cvedotnow/status/2116267306544177368)
