## Servers & dev tools

- **OpenSSH password-auth bypass on musl / Alpine (*sshole, CVE-2026-123158).** On Linux with musl libc and PAM disabled (Alpine's default `openssh-server`), if `PasswordAuthentication` is still `yes` and any account has a `$5$`/`$6$` hash, an attacker who knows a username with a `*` password field (key-only users, cloud `alpine`, etc.) can log in with any 257–1024 byte password. OpenSSH calls it critical; public write-ups and demos are circulating. glibc / PAM-on systems are not affected. Fixed upstream in **OpenSSH 10.6p2** (Nov 5); Alpine shipped patched packages across supported branches. **Do:** on Alpine or other musl+no-PAM hosts running sshd, `apk upgrade -U -a` (or install OpenSSH 10.6p2) and **restart sshd** (package upgrade alone does not); if you cannot patch yet, set `PasswordAuthentication no` and restart. Check logs for `Accepted password for` on accounts that should be key-only. [OpenSSH 10.6p2](https://www.openssh.com/txt/release-10.6p2) · [Alpine advisory](https://alpinelinux.org/posts/2026-11-05-openssh-password-authentication-bypass/) · [oss-security](https://www.openwall.com/lists/oss-security/2026/11/05/3)

- **APT can install a swapped package as root (CVE-2026-109518, High).** On Debian/Ubuntu with non-zero `Acquire::Retries` (default on Ubuntu 22.04+ / Debian 12+), an on-path attacker or malicious HTTP mirror can replace a verified `.deb` during a retry and get root via package scripts. HTTPS mirrors block the MitM path; snaps are unaffected. No KEV listing. **Do:** upgrade apt with retries disabled for the update itself — e.g. `sudo apt update && sudo apt upgrade -o Acquire::Retries=0` — to at least **2.4.15ubuntu0.1** (22.04), **2.8.4ubuntu0.1** (24.04), **3.2.1ubuntu0.1** (26.04), or Debian's **2.6.2 / 3.0.4**; prefer `https://` archive URLs going forward. [Ubuntu blog](https://ubuntu.com/blog/apt-vulnerability-fixes-available) · [Ubuntu CVE](https://ubuntu.com/security/CVE-2026-109518)

- **MariaDB ALTER TABLE partition conversion authz bypass (CVE-2026-102523).** An authenticated DB user can make `ALTER TABLE … CONVERT … PARTITION` touch table files they should not reach. Not known exploited. Fixed in **10.11.19, 11.4.13, 11.8.9, 12.3.3, 13.0.2**. **Do:** if you run MariaDB with partitioning, upgrade to those builds (or `--skip-plugin-partition` as a temporary workaround). [MariaDB advisory](https://github.com/MariaDB/server/security/advisories/GHSA-h4vr-wpff-jfx4) · [cve.now](https://cve.now/CVE-2026-102523)

- **Node.js HIGH-severity security releases land on/after Nov 11.** Lines **22.x, 24.x and 26.x** each get at least one HIGH fix; CVEs and component details are withheld until then. **Do:** plan the bump now and install the new builds as soon as they appear; EOL lines stay exposed. [Node.js blog](https://nodejs.org/en/blog/vulnerability/november-2026-security-releases)

- **Rust crates: Wasmtime sandbox escape + Azure Key Vault token leak + Arrow OOB.** Wasmtime/wasi on **macOS/FreeBSD** can escape via symlink rename (**CVE-2026-118688**); also wasi-http response-splitting / request-smuggling fixes. Azure Key Vault crates cache a rejected auth challenge scope and can later send a bearer token to an attacker endpoint (**RUSTSEC-2026-0437/0438/0439**). Apache Arrow Rust can OOB-read on crafted RunEndEncoded arrays (**CVE-2026-111959**). No known exploitation. **Do:** bump Wasmtime to **36.0.18 / 48.0.6–48.0.7 / 49.0.3–49.0.4** (match your line); `azure_security_keyvault_*` to **≥1.0.1**; bump `arrow`/`arrow-data` to **60.1.0 / 59.3.2 / 58.4.1 / 57.3.2** (match your line); run `cargo audit`. [Wasmtime GHSA](https://github.com/bytecodealliance/wasmtime/security/advisories/GHSA-m9f7-9w4p-gv38) · [RUSTSEC-2026-0439](https://rustsec.org/advisories/RUSTSEC-2026-0439) · [Arrow CVE](https://cve.now/CVE-2026-111959)

- **WordPress plugin “Security For WooCommerce” unauth admin create (CVE-2026-100109).** Versions **1.0.10–1.0.16** let unauthenticated callers create users (including administrators). No fixed version listed yet. **Do:** if installed, deactivate/remove the plugin now and audit for unknown admins; watch WPScan for a patched release. [cve.now](https://cve.now/CVE-2026-100109) · [WPScan](https://wpscan.com/vulnerability/b4d26eb3-ab32-456e-9f69-9ab300fdf44c/)

## Devices & accounts

- **Apple PAC-bypass bug added to CISA KEV (CVE-2024-27834, Nov 4).** Improper authentication / Pointer Authentication bypass in WebKit/Safari stack; CISA cites active exploitation (often chained after local r/w). Fixed earlier in **Safari 17.5**, **iOS/iPadOS 17.5** (and 16.7.8), **macOS Sonoma 14.5**. **Do:** confirm every Apple device and Safari are on those builds or newer; treat still-unpatched phones as high risk for watering-hole / malware chains. [CISA alert](https://www.cisa.gov/news-events/alerts/2026/11/04/cisa-adds-one-known-exploited-vulnerability-catalog) · [Safari 17.5](https://support.apple.com/en-us/120896)

- **Edimax BR-6208AC unauth command injection now has a public PoC (CVE-2026-122051, CVSS 10).** `/goform/mp` RCE, no login needed; firmware **1.32**; vendor silent, no patch listed. **Do:** if you own this router, take WAN management off the internet, replace the device if you can, and assume compromise if it was exposed. [cve.now](https://cve.now/CVE-2026-122051) · [PoC tree](https://github.com/fizz-is-on-the-way/Iot_vuls/tree/main/BR-6208AC/RCE_mp)

## Scams

- **WhatsApp account-hijack malware wave (Malaysia, Singapore, Brazil, Taiwan, Vietnam and others).** Compromised contacts push ZIP/ISO “invoices” / bank statements that drop Windows RATs; MyCERT/SingCERT and CZ amplified warnings. **Do:** disable auto-download of files, verify unexpected attachments out-of-band, turn on WhatsApp two-step verification, and never open ISO/ZIP from chat on a daily-driver PC. [X story](https://x.com/i/trending/2118257484414747130)

- **India CERT-In flags “CRAFTY FALCON” AI-assisted attacks on banks, fintech and crypto exchanges.** Actors abuse victims’ own APIs (tiny ₹1 test transfers, then larger drains) with automated tooling. **Do:** if you run or use exchange/API keys, alert on tiny unexpected transfers, tighten API allowlists/withdrawals, and rotate keys after any anomalous call. [X story](https://x.com/i/trending/2118204435696423169)
