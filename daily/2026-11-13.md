## Servers & dev tools

- **PostgreSQL 18.7, 17.12, 16.16, 15.20 and 14.25 are out, fixing 52 security bugs.** Many are CVSS 8.8 "executes arbitrary code" bugs that need a logged-in database user (type confusion, use-after-free in plperl/pltcl, `ts_rank_cd()`/`tsvector_delete()` overflows); also `pg_dump`/`pg_restore` injection when restoring untrusted dumps (CVE-2026-116314, -116318, -116330), dblink/subscription file append (CVE-2026-14661) and a pre-auth cancel-request spinlock leak (CVE-2026-116322). Not known exploited. This is the **final release for PostgreSQL 14**. **Do:** install the minor update and restart; read the post-update steps (reindex some GIN, `gist_trgm_ops` and bpchar B-tree indexes; new full backup if you use incremental backups); don't restore dumps from untrusted sources with old client tools; plan off 14. [PostgreSQL announcement](https://www.postgresql.org/about/news/postgresql-187-1712-1616-1520-1425-and-19-rc-2-released-3442/)

- **wfx-loot: 4,837 hijacked GitHub accounts pushed a CI secret stealer into repos they can write to.** Since Nov 10 the attacker opened ~61k–66k probe PRs titled `docs: dependency audit notes` (branch `wfx-docs`), then pushed commits like `ci: refresh build cache`, `chore: add ci helper` (an npm `postinstall` hook that also runs on dev machines) or `chore: add dependency audit workflow`, reverted them within minutes and deleted the run logs. Secrets confirmed stolen from at least 1,806 repos; ~50 compromised accounts publish to npm, PyPI, crates.io, Go or Packagist. Actively exploited. **Do:** search repos you can write to for those PR titles, branches and commits, and for missing workflow run numbers since Nov 10; if found, rotate every secret and cloud role the workflows could reach and your GitHub tokens; review recent `package.json` hooks before `npm install`/`bun install`; turn on 2FA and prune old tokens and collaborators. [Aikido](https://www.aikido.dev/blog/compromised-github-accounts-push-ci-secret-stealer-to-tens-of-thousands-of-repositories) · [OX Security](https://www.ox.security/blog/thousands-of-github-accounts-hijacked-with-wfx-loot-ci-secret-stealing-malware-via-github-actions-npm/)

- **AI-agent campaign ("MevBotResearch") is breaking into Solana validators and MEV/trading-bot servers to steal keys.** A researcher found Claude Code agent files that list ~5,900 target IPs and probe exposed ClickHouse, Redis, Docker, Grafana, SSH and Solana RPC; one reported chain went from a passwordless ClickHouse to SSRF to root (via logrotate), then keys read from disk and wallets drained in seconds. Actively used. **Do:** make sure no ClickHouse, Redis, Docker API, Grafana or RPC port is reachable from the internet without auth (bind to localhost/VPN, set passwords, firewall); keep hot-wallet and exchange API keys off internet-facing hosts and use withdrawal allow-lists. [researcher post on X](https://x.com/fr0gger_/status/2120682376078753921) · [attack-chain summary on X](https://x.com/AdvancedHacker/status/2120787406446088410)

- **Git 2.56.1 fixes code execution when recursively cloning a malicious repo (CVE-2026-111760, plus five other bugs).** A long path can overwrite a submodule's `.git` file with a symlink to attacker hooks. Not known exploited. Per a post on X, pip, uv, npm, cargo and Poetry can fetch submodules for git dependencies without you asking. **Do:** update Git to **2.56.1** (or 2.55.1 / 2.54.1 / 2.53.1 / 2.52.1 / 2.51.3 / 2.50.2), including on CI runners and in tools that bundle Git; until then avoid recursive clones and git-URL dependencies from untrusted sources. [GitHub blog](https://github.blog/open-source/git/git-security-vulnerabilities-announced-7/) · [X post](https://x.com/theomlondhe/status/2120882264468762848)

- **Apache httpd 2.4.71 fixes a critical mod_http2 heap corruption / RCE (CVE-2026-119618).** Affects 2.4.55–2.4.70 with HTTP/2 on (and mod_h2 2.0.8–2.0.42). Per X reports public PoCs exist; no confirmed exploitation. **Do:** upgrade to **2.4.71** or disable HTTP/2 (`Protocols http/1.1`) until you can. [Apache httpd security](https://httpd.apache.org/security/vulnerabilities_24.html)

- **Minor:** Portabase (database backup tool) unauthenticated path traversal CVE-2026-67449 (CVSS 9.8); Apache Airflow before 3.4.0 runs forged callbacks from an unauthenticated Celery broker (CVE-2026-68982; upgrade and password-protect Redis/RabbitMQ); Rust: `vodozemac` panic on malformed Ed25519 keys (RUSTSEC-2026-0510), `bsv-rs` transaction-parsing and Shamir-recovery flaws (RUSTSEC-2026-0497..0501), `eazip` symlink escape on Windows (RUSTSEC-2026-0503); more Hickory DNS CVEs all fixed in hickory-proto 0.26.2. [cve.now](https://cve.now/CVE-2026-67449) · [RustSec](https://rustsec.org/advisories/RUSTSEC-2026-0510.html)

Chrome for Android 157.0.8103.78 carries the same fixes. **Do:** update Chrome and relaunch (chrome://settings/help). [X story](https://x.com/i/trending/2120867178476097597)

## Crypto & scams

- **Update: Trezor confirmed implants in Safe 5 devices sold by reseller CryptoBilis (Aug 20–Sep 23, 2026).** Three tampered units had extra boards with a cellular modem that sent typed recovery words; Trezor shipped firmware **2.13.1** on Nov 11 to block the implants and cut ~80% of resellers. **Do:** if you bought a Trezor from a reseller, update firmware and, if it came from CryptoBilis, move funds to a new wallet with a new seed; buy hardware wallets direct. [Trezor on X](https://x.com/Trezor/status/2120880310300934641)
