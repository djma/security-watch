# Security digest — 2026-11-15
Covers about 24–36 hours up to 08:00 Asia/Shanghai. Checked CISA KEV (no new additions since Nov 13), RustSec, Chrome releases, Apple security releases, vendor advisory pages, @cvedotnow and X. The cve.now JSON feeds returned server errors this morning, so cve.now items below come from its X posts. Quiet weekend for big patches. Most urgent: a trading tool's wallets were drained after private keys ended up in its monitoring logs, fake Gate.io SDK packages on PyPI, a critical Dokploy root-command bug, and an unpatched public Windows SYSTEM exploit (SignDrop). No new Redis, ClickHouse, PostgreSQL, OpenSSH or Bun advisories beyond those already covered.

## Servers & dev tools

- **Proxima trading wallets drained through its SigNoz monitoring setup.** Proxima says diagnostic logs in its SigNoz observability stack captured private keys for wallets created, imported or exported in the past 15 days. Attackers took about 5,324 SOL (~$200–250K) from 870 wallets of 181 users. Proxima says it will cover all losses. The exact SigNoz flaw isn't named; posts on X point to CVE-2026-97055 (SigNoz before v0.143.0 shipped an empty default JWT secret that lets anyone forge admin sessions), but that link is unconfirmed. **Do:** if you used Proxima recently, move funds to a fresh wallet and don't send more to affected addresses. If you run SigNoz or any log/trace stack, upgrade SigNoz to **0.143.0+**, set a strong JWT secret, keep it off the public internet, and make sure keys, seeds, tokens and auth headers are never logged. [X story](https://x.com/i/trending/2121516666588901563) · [X post](https://x.com/StickyDev420/status/2121572256308441200)

- **Fake Gate.io SDK packages on PyPI.** `gateio-ws`, `gateio-sdk` and `gateio-client` (version 99.99.1) were flagged as malicious on Nov 14 and detonated in sandboxes. They impersonate exchange API clients, so they target people who build trading bots. **Do:** check lockfiles and environments for these names. If you installed one, treat that machine as compromised and rotate every exchange API key and secret it could read. Install exchange SDKs only from the exchange's documented package name. [X post](https://x.com/w0rmsign/status/2121721380076949896) · [X post](https://x.com/infrastack_ai/status/2121740020176626163)

- **Dokploy: critical root command injection (CVE-2026-129433, CVSS 9.4).** Any logged-in organization member can inject shell commands through the Compose backup `serviceName` field, and they run as root on the host (with Docker socket access). Not known exploited. **Do:** upgrade self-hosted Dokploy to **0.31.1** and review who has organization access. [cve.now on X](https://x.com/cvedotnow/status/2121712936313876877) · [CVE](https://www.cve.org/CVERecord?id=CVE-2026-129433)

- **New Rust advisories (Nov 13).** `quinn-proto`: a peer can open streams beyond the limit, and a long Retry token can panic a client or make it allocate more than 10 GiB (RUSTSEC-2026-0523/0524, fixed in **0.11.19**). `quinn-udp`: the receive loop can spin after a truncated datagram (RUSTSEC-2026-0538). `libp2p-gossipsub`: remote panics and unbounded memory growth (RUSTSEC-2026-0534..0537). `libp2p-quic`: remote panic (RUSTSEC-2026-0525). `libp2p-rendezvous`: unlimited registrations (RUSTSEC-2026-0526/0527). `hickory-net` DNSSEC proof bypasses (RUSTSEC-2026-0539..0541). RustSec also back-filed older `russh` pre-auth memory-exhaustion bugs (RUSTSEC-2026-0493 / -0494, fixed in 0.61.x; RUSTSEC-2024-0450, fixed in 0.44.1), which the current 0.65.1 already covers. **Do:** run `cargo update` and `cargo audit`; bump quinn to 0.11.19+. [RustSec](https://rustsec.org/advisories/) · [RUSTSEC-2026-0524](https://rustsec.org/advisories/RUSTSEC-2026-0524.html)

- **Minor:** Control Web Panel account takeover through poisoned password-reset links (CVE-2026-124020), fixed in **1.30.6**. Seafile SeaDoc RCE with only a public share token (CVE-2026-129167), fixed in **2.0.11 / 3.0.8**. NginxPulse unauthenticated SQL injection (CVE-2026-129171), fixed in **1.6.26**. ## Devices & accounts

- **SignDrop: public, unpatched Windows exploit to SYSTEM.** Researcher Nightmare Eclipse released an exploit that abuses Microsoft's CLFS hardening and Defender to get SYSTEM rights from a normal local account. Ars Technica reports it works on some Windows 26H2 systems. No CVE or patch yet, and Microsoft says it has no evidence of attacks. It needs code already running on the PC, so it's a second-stage risk. **Do:** don't run untrusted downloads or "tools"; watch for an out-of-band or December Patch Tuesday fix. [X post](https://x.com/DSolutionsIA/status/2121657378885996801) · [X post](https://x.com/threatroundup/status/2121589386227617894)

- **Home routers: critical bugs in old D-Link and TRENDnet models.** D-Link DIR-600L has an unauthenticated stack overflow in its login page (CVE-2026-129353, CVSS 10). TRENDnet TEW-657BRM has unauthenticated memory corruption (CVE-2026-129351, CVSS 10). Both are old models, and no fixes are listed. **Do:** if you still use either, replace it, or at least turn off remote admin. [cve.now on X](https://x.com/cvedotnow/status/2121747903186112680) · [cve.now on X](https://x.com/cvedotnow/status/2121741112968655206)

- **Gaming PC utilities: local-to-SYSTEM driver bugs** in Kingston FURY CTRL (CVE-2026-129261) and CoolerMaster MASTERPLUS+ (WinRing0x64.sys, CVE-2026-129255). **Do:** uninstall RGB/fan utilities you don't need. [cve.now on X](https://x.com/cvedotnow/status/2121710159466566043)

- **Unverified:** a seller claims an 80 GB database on 46.3M people in Spain (names, ID numbers, addresses). If you're in Spain, expect ID-based phishing. [X story](https://x.com/i/trending/2121711317719372168)

## Crypto & scams

- **MANTRA pauses unbonding after the Keplr/Web3Auth key leak.** Attackers are using private keys leaked in the earlier Web3Auth/Keplr social-login incident to unstake and drain at least $1.82M from more than 7,800 Cosmos wallets (Nov 1–12). MANTRA froze new unbonding for 7 days. **Do:** if you ever created a Keplr wallet with Google or other social login, move everything to a new seed-phrase or hardware wallet now. Staked funds count too: users who are mid-unbonding should redelegate. [X story](https://x.com/i/trending/2121216487893414088)

- **Kava Lend drained** through a dormant BUSD market (about $3.3–3.7M per reports). KAVA fell about 50%, and Upbit, Bithumb and Coinone froze deposits. **Do:** withdraw from Kava Lend until there's a post-mortem. [X story](https://x.com/i/trending/2121597878724591810)

- **Unocoin hot wallet hit (~$200K)** using compromised backup signing keys. The exchange says customers are unaffected. **Do:** nothing beyond watching for "refund" phishing. [X story](https://x.com/i/trending/2121615811320098923)

- **Post-hack recovery scams:** after each hack, "wallet recovery" accounts reply to victims on X. **Do:** never pay or share a seed phrase with recovery services.
