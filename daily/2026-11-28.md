Covers about 24–36 hours up to 08:00 Asia/Shanghai (a quiet US holiday stretch). Checked CISA KEV (Nov 27 additions: Drupal CVE-2026-136716 and two GeoServer flaws), RustSec (up to RUSTSEC-2026-0603), the cve.now feeds, Chrome releases (only a ChromeOS LTS update), Apple security releases (nothing new since Nov 18), ClickHouse, Redis, Bun and OpenSSH releases, @cvedotnow and X. ## Servers & dev tools

- **Airbyte (self-hosted Core) supply-chain compromise: platform 2.5.0 images and nine connector images were tampered on Nov 25.** The tampered images send the credentials configured for each connection (database, warehouse and API keys) to an external server. The window ran from about 10:35 AM to 1:40 PM PT on Nov 25 (02:35–05:40 Nov 26 Asia/Shanghai). **Do:** if you run Airbyte Core, check image digests against the advisory's tables, upgrade to **2.6.0** (which also fixes Java4Shell CVE-2026-114938), and rotate the credentials of every connection that ran an affected image, including the database users in Postgres, Snowflake or BigQuery. [Airbyte advisory](https://airbyte.com/blog/advisory-for-open-source) · [X: @AirbyteHQ](https://x.com/AirbyteHQ/status/2125799181709451490)
- **Malicious packages flagged Nov 27:** npm `bun-types-loader` (it pretends to be Bun typings; [GHSA-5h6f-8w4g-h62p](https://github.com/advisories/GHSA-5h6f-8w4g-h62p)), npm `react-schedule-it` (every published version), and PyPI `qwentts-gradio` **0.3.0**. **Do:** search your lockfiles and `bun.lock` for them. If one was installed, remove it and rotate every secret that machine or CI runner could read. [X: infrastack (bun-types-loader)](https://x.com/infrastack_ai/status/2126346284412076172) · [X: infrastack (react-schedule-it)](https://x.com/infrastack_ai/status/2126348854513860925) · [X: infrastack (qwentts-gradio)](https://x.com/infrastack_ai/status/2126416925253374448)
- **Linux kernel nfsd CVE-2026-99362 (9.8): public exploit code on GitHub since Nov 27.** A crafted NFSv4.1 SEQUENCE request causes an out-of-bounds kernel write, and the client can read back leaked memory. It's not reported as exploited. **Do:** update the kernel (Debian 12: **6.1.192-3**; other distros, check your vendor). Don't expose NFS (port 2049) to the internet. [cve.now](https://cve.now/CVE-2026-99362) · [Debian LTS](https://lists.debian.org/debian-lts-announce/2026/11/msg00069.html)
- **GeoServer: CVE-2026-120705 and CVE-2026-129243 added to CISA KEV Nov 27 (exploited).** These are unauthenticated XML injection and authorization-bypass flaws that chain with three related CVEs into remote code execution. **Do:** if you self-host GeoServer, apply the vendor fix now and keep it off the public internet until it's patched. [CISA KEV](https://www.cisa.gov/known-exploited-vulnerabilities-catalog)

  - **ClickHouse** published more patch builds on Nov 27: **26.11.4.11 / 26.10.15.10 / 26.9.41.4 / 26.8.49.6-lts / 26.3.73.9-lts**. There's no security advisory, but it's worth staying on the latest build of your branch. [ClickHouse releases](https://github.com/ClickHouse/ClickHouse/releases)

[RustSec](https://rustsec.org/advisories/)

## Devices & accounts

- **RealVNC CVE-2026-137738 (9.8): pre-login remote code execution over UDP connections**, possibly as root on some platforms. It affects Viewer, Server, Connect, On-Demand Assist and the iOS/Android apps on cloud-brokered and direct UDP connections. TCP-only direct connections aren't exposed. It's not reported as exploited. **Do:** update to **Viewer / Connect 8.6.2, Classic Viewer 7.18.3, Server 7.19.1, On-Demand Assist 3.5.0, and Viewer iOS/Android 4.9.6**. [RealVNC advisory](https://help.realvnc.com/hc/en-us/articles/40824627217949-Security-Advisory-UDP-based-connection-vulnerability)
- **Telegram is warning iPhone users on older iOS about mass hacking.** Pavel Durov says just opening a website can be enough. This matches the one-tap iPhone exploit kits reported this month (such as MoldyRoost). **Do:** update to **iOS 27.2.1 or 26.7.3** (**18.7.12** on XS/XR), and turn on Lockdown Mode on any iPhone you can't update. [X: @durov](https://x.com/durov/status/2126453172403355908) · [Apple security releases](https://support.apple.com/en-us/100100)
- **ChromeOS LTS-150 (150.0.7871.290)** shipped on Nov 27 with backported fixes, including one critical (CVE-2026-126885). Desktop Chrome has nothing new since Nov 24. [Chrome Releases](https://chromereleases.googleblog.com/)

## Scams

- **SparkCat-style seed-phrase theft in a food-ordering app:** Apple blocked the Wukong (also called Gokoo) iOS app, which has about 135,000 users in China and Southeast Asia, after it was found using OCR to scan photo libraries for wallet seed phrases and private keys. **Do:** delete it if you have it. Never keep seed phrases or key screenshots in your photo library, and limit apps to selected photos only. [X news](https://x.com/i/trending/2125947308986515918)
- **"Wrench attacks" from on-chain visibility:** a crypto exec described a Dubai apartment being targeted after their hot-wallet activity was traced to them. **Do:** keep your identity separate from active wallets, and don't post balances or trades publicly. [X news](https://x.com/i/trending/2126450547930570970)
