## Devices & accounts

- **Chrome 157 is out (Nov 3): 213 security fixes, including 7 Critical.** Builds are 157.0.8103.38 on Linux/Android and 157.0.8103.38/.39 on Windows/Mac. Criticals include Dawn buffer overflows (CVE-2026-121156, CVE-2026-121247), ANGLE memory corruption (CVE-2026-121229) and use-after-free bugs in WebGL, Prerender, Geometry and Core. No known exploitation yet. **Do:** update Chrome/Chromium (and Edge/Brave when they roll the same Chromium) and restart the browser; don't postpone this one. [Chrome releases](https://chromereleases.googleblog.com/2026/11/stable-channel-update-for-desktop.html)

## Servers & dev tools

- **WordPress upgrade-window RCE (CVE-2026-119977) is now on CISA's exploited list (added Nov 3).** Unauthenticated attackers can hit predictable staging paths during a full-package core upgrade and get code execution. Affects 4.7 through 7.1.3; fixed in **7.1.4** (and matching backports). Separate from yesterday's REST-API bug (CVE-2026-63030). **Do:** update WordPress core to 7.1.4 or later (auto-updates on), avoid leaving sites mid-upgrade, and check for unfamiliar admin users and PHP files. [cve.now](https://cve.now/CVE-2026-119977) · [WordPress 7.1.4](https://wordpress.org/news/2026/10/wordpress-7-1-4/) · [cve.now on X](https://x.com/cvedotnow/status/2117721119788581350)
- **Update: Ubuntu put fixed kernels for CVE-2026-98432 (remote TCP use-after-free, CVSS 9.8) in the -proposed pocket.** Versions: 22.04 → 5.15.0-203.213, 24.04 → 6.8.0-149.149, 26.04 → 7.0.0-43.43; 26.10 already fixed in 7.3.0-10.10. Not in normal `updates` yet (still qualification-testing). Scans and threat-actor interest are being reported. **Do:** on Ubuntu 22.04+, either wait for the updates pocket or install the matching kernel from `-proposed` only (don't enable broad proposed upgrades) and reboot; on other distros, install the vendor kernel and reboot. Disabling MPTCP alone is not enough. [Ubuntu blog](https://ubuntu.com/blog/fixes-available-in-proposed-pocket-for-cve-2026-98432) · [X story](https://x.com/i/trending/2117104662436286776)
- **PHP "php2shell" RCE (CVE-2026-109619) now has a public Nuclei scanner template**, on top of many GitHub PoCs. Already on KEV and actively exploited; stale global state after a fatal error can become remote code execution. **Do:** upgrade PHP to **8.2.35, 8.3.36, 8.4.27 or 8.5.12** (or whatever your distro packages with those fixes). [cve.now](https://cve.now/CVE-2026-109619) · [PHP advisory](https://github.com/php/php-src/security/advisories/GHSA-6wmf-4rv5-p3rp)
- **Self-hosted GitLab CI regex RCE (CVE-2026-97229, CVSS 10) now has Metasploit + public PoCs and a Nuclei template.** Already on KEV; GitLab.com is patched. Fixed in **19.2.8, 19.3.5 and 19.4.2**. **Do:** if you run self-managed GitLab, upgrade to those builds now and keep open registration off. [cve.now](https://cve.now/CVE-2026-97229) · [cve.now on X](https://x.com/cvedotnow/status/2117709543136268695)
- **Docker Sandboxes can escape to the host via Git config (CVE-2026-121614).** When a sandbox mounts the host workspace read-write, a repo-controlled Git setting (e.g. `core.fsmonitor`) can run a program on the host outside the microVM. Fixed in **0.50.0**. Separately, **Docker Buildx Bake skips filesystem-entitlement consent under `--progress=rawjson` (CVE-2026-93325)**; fixed in **0.37.2**. No known exploitation. **Do:** upgrade Docker Sandboxes to 0.50.0+ and Buildx to 0.37.2+; until then avoid direct-mode sandboxes on untrusted repos and don't bake untrusted defs with rawjson progress. [Sandboxes on cve.now](https://cve.now/CVE-2026-121614) · [Buildx on cve.now](https://cve.now/CVE-2026-93325)
- **Rust crates: new RustSec advisories.** The widely used **`zip` crate** aborts the process on a crafted symlink entry (RUSTSEC-2026-0429 / CVE-2026-115909); fixed in **9.0.0+** (most recent downloads were still on affected versions). **`calamine`** (Excel parser) can panic or OOM on malformed workbooks (RUSTSEC-2026-0436); fixed in **0.38.0**. Also: thrift unbounded allocation (RUSTSEC-2026-0435, fixed in 0.23.0). **Do:** run `cargo audit` / `cargo update`, especially if you extract ZIPs or parse spreadsheets from untrusted input. [RUSTSEC-2026-0429](https://rustsec.org/advisories/RUSTSEC-2026-0429) · [RUSTSEC-2026-0436](https://cve.now/RUSTSEC-2026-0436)

## Crypto & accounts

- **GitBook disclosed an infrastructure breach (Nov 2) involving AI agents.** Integration tokens, Git Sync secrets and personal API tokens may have been accessed; GitBook revoked every personal API token. Some crypto projects (e.g. PancakeSwap) moved docs off the platform. This is broader than yesterday's Trade.xyz docs-tamper note. **Do:** if you use GitBook, rotate every integration/Git Sync/API token on your side, treat any docs links from that window as untrusted, and watch for phishing that uses stolen project context. [X story](https://x.com/i/trending/2117674986655584667)
- **Trust Wallet users report sudden unauthorized drains (USDT and others).** Blockchain shows the transfers; root cause is unclear (phishing, prior approvals, Discord fake support, or a wallet bug). Not confirmed as a Trust Wallet vulnerability. **Do:** if you use Trust Wallet, move funds you care about to a hardware or fresh wallet, revoke token approvals, ignore Discord "support", and open tickets only through the official site you type yourself. [X story](https://x.com/i/trending/2117752195575935322)
