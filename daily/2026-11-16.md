## Servers & dev tools

- **Fake Claude Code package on npm: `@claudecode/cli`.** GitHub flagged it as malware on Nov 13 (GHSA-vp2q-gp5r-xh5j). Every version is malicious and there is no safe release. The real package is `@anthropic-ai/claude-code`. **Do:** search lockfiles and global installs (`npm ls -g`, `bun pm ls -g`) for `@claudecode/cli`. If you find it, treat the machine as compromised and rotate every key, token and exchange/API secret it could reach, from a different machine. [GitHub advisory](https://github.com/advisories/GHSA-vp2q-gp5r-xh5j) · [X post](https://x.com/Sujeet/status/2122110239483072548)

- **Luxor Commander abused to hijack ~64,000 Bitcoin miners.** Attackers redirected about 13 EH/s from just over a dozen client accounts to the OCEAN pool, paying out to their own address. Luxor says it fixed the flaw within about two hours, found no data leak, and will compensate affected operators. **Do:** if you use Luxor Commander or any remote mining-management tool, check pool settings and payout addresses on every rig, and turn on 2FA and IP allow-lists where offered. [Luxor on X](https://x.com/luxor/status/2122018094914601464) · [CoreX alert](https://x.com/CoreX_Hosting/status/2121802488898863443)

- **Tor relay operators:** an ongoing DDoS against relays (especially HSDirs) since late October. Tor released emergency version **0.4.9.17** on Nov 13. **Do:** relay operators should upgrade. [X story](https://x.com/i/trending/2122109256207904972)

- **Minor (cve.now, not known exploited):** NginxPulse unauthenticated SQL injection via PostgreSQL superuser functions (CVE-2026-129171), fixed in **1.6.26**. C-Kermit remote command injection (CVE-2026-129124), fixed in **11.1.515**. listmonk 2FA bypass by brute-forcing TOTP codes (CVE-2026-128332), fixed in **7.0.0-beta.2**. SiYuan admin access-code brute force (CVE-2026-126265), fixed in **3.8.9**. Tactical RMM file read leading to commands on managed agents (CVE-2026-129165). [cve.now on X](https://x.com/cvedotnow/status/2122114579228397619) · [cve.now on X](https://x.com/cvedotnow/status/2122101240561557593) · [cve.now on X](https://x.com/cvedotnow/status/2122071545006731542)

## Devices & accounts

- **Trader's desktop taken over, Hyperliquid positions closed and funds withdrawn.** A trader reports attackers got remote control of his computer, watched his public posts about short positions for five days, then closed his Bitcoin trades on Hyperliquid and withdrew almost everything through MetaMask to Tornado Cash, after a $10 test withdrawal. He blames a WhatsApp Desktop auto-download; others on X suspect an AI tool on the same machine was the way in. The cause is unconfirmed. **Do:** turn off WhatsApp/Telegram media and document auto-download on desktop. Keep trading and wallet keys on a separate machine or browser profile with no AI agents or chat apps. Use withdrawal allow-lists and withdrawal-only 2FA on exchanges, and don't post live positions. [Victim's post](https://x.com/harleyfoote_/status/2121288511785410732) · [X story](https://x.com/i/trending/2121761514751250724)

- **Fake Google Meet "certificate error" pages push malware.** The page shows a fake certificate error and offers a "security update", delivered through Windows ClickOnce or a macOS AppleScript. **Do:** Meet runs in the browser and never needs an update download. Close any page that asks you to install one. [X post](https://x.com/Malwarehunterr/status/2122057038394269974)

- **Apple certificate-validation bypass (CVE-2026-112652) has a public exploit.** A malicious app could impersonate servers on iOS, iPadOS, macOS and visionOS below the fixed versions. The post doesn't list the fixed versions. **Do:** make sure you're on Apple's latest releases (iOS 27.2.1 / 26.7.3 / 18.7.12, macOS 27.2.1 / 26.7.3 / 15.8.3, all from Nov 9). [X post](https://x.com/infrastack_ai/status/2121622987845841081) · [Apple security releases](https://support.apple.com/en-us/100100)

- **Android:** cve.now newly rated 14 November-bulletin CVEs as critical (worst CVE-2026-55335, 9.8 RCE). **Do:** install the November security patch when your phone offers it. [cve.now on X](https://x.com/cvedotnow/status/2122060981618507819)

## Crypto & scams

- **Coinone (Korea) support-contractor breach.** Support chats held at an outsourced contractor leaked. Depending on what people shared there, this may include names, phones, emails, birth dates, bank accounts, passwords, ID numbers, addresses and wallet info. Coinone says funds and trading systems weren't touched. Support is now email-only. **Do:** if you've ever contacted Coinone support, change any password you shared or reuse elsewhere, and expect convincing fake "Coinone support" calls and messages. Never give support a password or 2FA code. [X post](https://x.com/RichMarketingHQ/status/2121896233643978982) · [X story](https://x.com/i/trending/2121916190125949044)

- **Still live:** MANTRA's unbonding pause after the Keplr/Web3Auth key leak, and the Proxima/SigNoz key-in-logs drain (see [2026-11-15](https://djma.github.io/security-watch/daily/2026-11-15.md)). Keep watching for "wallet recovery" scam replies under every hack post.
