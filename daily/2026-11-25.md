## Servers & dev tools

- **Drupal core CVE-2026-132165 (SA-CORE-2026-017, "highly critical"): exploited since Nov 19, and added to CISA KEV Nov 24.** Under certain conditions an attacker can use `install.php` to reinstall the site, which leads to takeover or code execution. **Do:** update to **10.6.22 / 11.3.22 / 11.4.13**. Block `/core/install.php` at the web server (check that it returns 403/404), and make `settings.php` read-only to the web server user. If the site was exposed before you patched, check it for new admin users and changed files. [Drupal SA-CORE-2026-017](https://www.drupal.org/sa-core-2026-017) · [BleepingComputer](https://www.bleepingcomputer.com/news/security/drupal-patches-critical-rce-flaw-warns-exploits-may-surface-quickly/)
- **Valkey (Redis fork): four CVEs published Nov 24.** Three of them (cluster PUBLISH heap overflow CVE-2026-136156, Lua debugger use-after-free CVE-2026-136155, RDMA use-after-free CVE-2026-136157) are already fixed in the releases from Nov 18 (**9.1.4 / 9.0.8 / 8.1.12 / 8.0.13 / 7.2.16**). The fourth is in the **Valkey JSON module** (CVE-2026-136158, 8.8): `$..*` paths with JSON.ARRAPPEND/ARRINSERT/ARRPOP/ARRTRIM/CLEAR cause a use-after-free that has been developed into RCE. All four need a logged-in user. None is known exploited. **Do:** run the versions above, and update **valkey-json to 1.0.3** if you load it (it's in valkey-bundle). Use ACLs to keep app users away from `JSON.*` mutators, `EVAL`/`SCRIPT` and `PUBLISH` if they don't need them. Redis itself has no matching advisory. [cve.now: JSON](https://cve.now/CVE-2026-136158) · [cve.now: cluster](https://cve.now/CVE-2026-136156) · [NVD: CVE-2026-136155](https://nvd.nist.gov/vuln/detail/cve-2026-136155)
- **Idunno.AntiCsrf (ASP.NET) CVE-2026-131914: unauthenticated deserialization RCE, exploited and added to KEV Nov 24.** There's no patched version. **Do:** remove the package and switch to ASP.NET Core's built-in antiforgery. [cve.now](https://cve.now/CVE-2026-131914) · [X: SecAlerts](https://x.com/SecAlertsCo/status/2125379068098916716)
- **ruflo (npm AI-agent package, ~62K downloads a week) CVE-2026-59726 (critical):** the default Docker Compose setup exposes its MCP bridge to the network without auth, so anyone who can reach it can run code. **Do:** update to **3.16.3**, and keep MCP ports bound to localhost. [X: PatchRadar](https://x.com/PatchRadarDev/status/2125335457655406800)

## Crypto & scams

- **COLDCARD weak-seed postmortem (Nov 23): attackers rebuilt keys offline and took 1,778.84 BTC (~$107M).** Firmware from March 2021 to July 2026 used a software PRNG instead of the hardware RNG. Coinkite matched 236 customer accounts to losses and says the true number is likely higher. **Do:** if a COLDCARD made your seed before **4.2.0 (Mk2/Mk3), 5.6.0 (Mk4/Mk5), 1.5.0Q (Q) or 6.6.0X/6.6.0QX (Edge)**, and you didn't add 50 or more private dice rolls, move your funds to a new seed generated on fixed firmware. Updating the firmware doesn't repair an old seed. [Coinkite postmortem](https://blog.coinkite.com/coldcard-postmortem-published/) · [Coinkite advisory](https://blog.coinkite.com/coldcard-mk3-seed-generation-warning/) · [Bitcoin Magazine](https://bitcoinmagazine.com/news/coldcard-postmortem-seed-flaw)
- **Bullpen trading terminal breach: 18–19 early-beta accounts (opened Apr–Jun 2024) were drained, including a well-known trader's wallet (~$2–2.6M).** The accounts had Solana private keys imported. **Do:** if you ever imported a private key into a trading terminal or bot, move the funds to a fresh wallet and delete the key from the service. Prefer services that never hold your key. [Decrypt](https://decrypt.co/383889/ansem-meme-coin-crashes-wallet-drain-bullpen-security-breach) · [CoinDesk](https://www.coindesk.com/markets/2026/11/24/a-wallet-linked-to-popular-crypto-trader-ansem-sold-usd2-million-in-memecoins-as-his-namesake-token-cratered)
- **Still live:** Pump.fun's private-key import before Nov 30, MoldyRoost iPhone ads, and GL.iNet GoodCloud firmware ([2026-11-24](https://djma.github.io/security-watch/daily/2026-11-24.md)).
