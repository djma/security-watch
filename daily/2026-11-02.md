# Security digest — 2026-11-02
Covers about 24 hours up to 08:00 Asia/Shanghai. Checked CISA's exploited-bugs list (KEV, no new additions since Oct 28 beyond older entries getting public exploits), the cve.now feeds and X. No new Chrome or Apple security releases beyond those already covered.

## Crypto & payments

- **BTCPay Server hot wallets are being drained right now.** The BTCPay team says it's receiving reports of attackers sweeping hot wallets on self-hosted instances and urges everyone to shut instances down until its investigation ends. Cause, affected versions and losses aren't known yet; version 2.4.7 (Oct 29) fixed 85 security issues, one critical. **Do:** if you run BTCPay with a hot wallet, run `./btcpay-down.sh` now, move funds you don't need to cold storage, and when it's back, update to the latest release and prefer a watch-only/hardware-wallet setup so keys never sit on the server. [The Block on X](https://x.com/TheBlockCo/status/2117030702323728469) · [Cointelegraph on X](https://x.com/Cointelegraph/status/2117032533938549058)
- **Fake "prop firm giveaway" phishing targets traders.** Blue Guardian customers got emails saying they'd won $10,000 funded accounts, linking to the lookalike `blueguradian.com` that asks you to connect a wallet. The firm blames a leaked API key in its email marketing tool. **Do:** never connect a wallet from an email link; type trading and exchange sites yourself and treat "you won" mail as phishing. [X](https://x.com/i/trending/2116998392547254275)

## Servers & dev tools

- **Canonical LXD lets attackers log in as any trusted client (CVE-2026-112816, CVSS 10.0).** A crafted certificate chain on the LXD HTTPS API gives full control of the cluster and its containers/VMs; public proof-of-concept code is on GitHub, no exploitation reported yet. **Do:** upgrade LXD to 4.0.15, 5.0.11, 5.21.9 or 6.10.1 (`snap list lxd` to check), and keep the LXD API (port 8443) off the internet. [Ubuntu advisory](https://discourse.ubuntu.com/t/security-advisory-critical-vulnerability-found-in-canonical-lxd-and-microcloud/90557) · [cve.now](https://cve.now/CVE-2026-112816)
- **Update: Linux kernel TCP bug CVE-2026-98432 still unpatched in major distros.** Posts on X report Ubuntu and RHEL hadn't shipped fixed kernels as of Nov 1, while 34 public exploit repos exist. **Do:** install your distro's kernel update as soon as it lands and reboot; meanwhile minimize exposed TCP ports and check that `sysctl net.ipv4.tcp_migrate_req` is 0 (the migration path is one of the two bug paths). Fixed upstream in 5.10.272, 5.15.223, 6.1.190, 6.6.159, 6.12.113, 6.18.56, 7.2.10. [cve.now](https://cve.now/CVE-2026-98432) · [X](https://x.com/i/trending/2116383873907183996)
- **Self-hosted Gitea RCE (CVE-2026-60004) has fresh public exploit code.** Already on CISA's exploited list since August; default installs with open self-registration are the easy target. **Do:** upgrade Gitea to 1.27.1 or later and turn off open registration if you don't need it. [Gitea advisory](https://github.com/go-gitea/gitea/security/advisories/GHSA-rcr6-4jqh-j84m) · [cve.now on X](https://x.com/cvedotnow/status/2116985790320214189)
- **Reminder: ClickHouse CVE-2026-116366 fixed builds are on Docker Hub.** Nothing new beyond yesterday's PoC, but if you haven't patched: 26.10.3.7, 26.9.27.3, 26.8.36.3 or 26.3.62.3; nothing is listed for 26.7 or older, so upgrade off those branches. [X](https://x.com/beuchelt/status/2116996955234504823)

## Devices & accounts

- **iPhone 11 and older can't fully protect a phone-based crypto wallet.** OneKey's founder points out that unpatchable BootROM flaws (checkm8-class) let someone with brief physical access run code before iOS loads. **Do:** don't keep meaningful wallet seeds on an iPhone 11 or older; use an iPhone 12+ or a hardware wallet, and a long passcode. [X](https://x.com/i/trending/2116800638038511890)
- **Chainalysis customer data accessed.** Names, emails and roles of platform users were exposed; no passwords. **Do:** if you have a Chainalysis account, expect targeted phishing using those details. [X](https://x.com/i/trending/2116268578500493645)
