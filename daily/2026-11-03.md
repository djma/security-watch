## Crypto & payments

- **Update: BTCPay Server hot-wallet drains now have an affected-version range.** Reports say the drained servers were on 2.4.1 or earlier (attackers got admin access), none on 2.4.2 or newer were hit, and wallets held off the server (hardware/watch-only) were safe; tens of BTC and LTC moved. **Do:** if you ever ran an older instance, update to 2.4.7 or later, treat the old admin credentials, API keys and any hot-wallet seed as compromised, sweep remaining funds to a fresh wallet, and keep keys off the server. [BTCPay story on X](https://x.com/i/trending/2117031294206988727)
- **Mercado Bitcoin (Brazil's largest exchange) confirmed a breach on Nov 2 and suspended services.** Analysts estimate over $40M in suspicious transfers; Tether froze 4.5M USDT. Separately, ZachXBT reported a suspected $106M theft on Nov 1 from an unnamed EU entity's exchange accounts. **Do:** if you hold funds or API keys on any exchange, use withdrawal address allowlists and hardware-key 2FA, delete unused API keys, and restrict API keys by IP and to no-withdraw permissions. [X story](https://x.com/i/trending/2117240097997484033)
- **Fake "SKR Claim" app appeared in Solana Mobile's dApp Store for about an hour (Nov 1)** after attackers got into the publishing portal; it asked for seed phrases for a fake airdrop. Solana Mobile removed it and is wiping it from devices. **Do:** if you installed it or entered a seed phrase, move funds to a new wallet right away; deleting the app isn't enough. No legitimate airdrop needs your seed phrase. [X story](https://x.com/i/trending/2116978256545010134)
- **Trade.xyz (Hyperliquid perps front end) had its GitBook docs tampered with on Nov 2.** It says only documentation was affected and funds were safe, and it was restored by 9:15 AM ET. **Do:** don't connect a wallet or sign anything from links that were in its docs that morning; reach the app by typing the address. [X story](https://x.com/i/trending/2117283305003651121)

## Servers & dev tools

- **WordPress < 7.0.2 REST API RCE (CVE-2026-63030) is in the exploited-bugs feed and has public exploit code.** A REST API batch-route confusion chains into SQL injection and code execution on the server. **Do:** update WordPress core to 7.0.2 or later (auto-updates on), and check for unfamiliar admin users and PHP files. [cve.now](https://cve.now/CVE-2026-63030)
- **PostgreSQL ODBC driver (psqlODBC) fixes eight memory-safety and SQL-injection flaws (CVE-2026-120057 to CVE-2026-120064).** They affect apps that connect to Postgres through psqlODBC, mainly when talking to an untrusted server; no known exploitation and no public exploit. **Do:** update psqlODBC to 18.00.0006 if you use it (not needed for the Postgres server itself or for libpq/JDBC/Rust drivers). [cve.now](https://cve.now/CVE-2026-120057) · [cve.now on X](https://x.com/cvedotnow/status/2117337869761069537)
- **Docker can bypass UFW and expose Postgres (5432) and Redis (6379) to the internet.** A post on X describes bots reaching published container ports within minutes on fresh VPS instances and abusing Redis `REPLICAOF` and `CONFIG SET` to get code execution. This is a known Docker behavior, not a new CVE, but it is being actively abused. **Do:** bind published ports to `127.0.0.1` (`-p 127.0.0.1:5432:5432`), put rules in the `DOCKER-USER` chain instead of relying on UFW, set Redis `requirepass`/ACLs, and test from outside with `nmap`. [X](https://x.com/WorldCyberNewsX/status/2117270511268868413)
- **Update: Linux kernel CVE-2026-98432 (remote TCP use-after-free, CVSS 9.8) is still unpatched on Ubuntu.** X reports say Debian, SUSE, AlmaLinux and Amazon Linux have shipped fixes, Ubuntu's supported releases had not as of Nov 2, and a working exploit exists. **Do:** on non-Ubuntu hosts install the kernel update and reboot; on Ubuntu, check `apt list --upgradable | grep linux-image` daily and restrict exposed TCP ports until it lands. [cve.now](https://cve.now/CVE-2026-98432) · [X story](https://x.com/i/trending/2117104662436286776)
- **Self-hosted Plex Media Server SSRF (CVE-2026-96652) now has a public Nuclei scanner template**, and the **Gogs file-overwrite bug (CVE-2025-8110)** has a public PoC. Both are on the exploited list. **Do:** update Plex Media Server to the latest release and don't expose it directly to the internet; update Gogs to the latest release or move to a maintained fork, and disable open registration. [Plex on cve.now](https://cve.now/CVE-2026-96652) · [Gogs on cve.now](https://cve.now/CVE-2025-8110)
- **Rust crates: new RustSec advisories.** Among them: wasmtime panics and type-confusion bugs (RUSTSEC-2026-0422 and -0423; fixed in 48.0.8, 49.0.5 and 50.0.1 per X posts) and a BLAKE2b wrong-tag bug after `reset()` with a different-length key (RUSTSEC-2026-0428). Several small crates (`ant-releases`, `sn-releases`, `nix-nar`) have archive-extraction path-traversal bugs. **Do:** run `cargo audit` and `cargo update` on projects that use them. [RUSTSEC-2026-0428](https://rustsec.org/advisories/RUSTSEC-2026-0428.html) · [RUSTSEC-2026-0422 on X](https://x.com/thecratedigest/status/2117323510808777150)
- **Playwright 1.64.1 bundles an out-of-date Chromium (156.0.8078.4)**, behind the critical fixes in Chrome 156.0.8078.73+, and runs without the sandbox by default. **Do:** update Playwright to a build with the current Chromium, and run browser automation or AI agents browsing arbitrary sites in a container or VM, not on your main machine. [X story](https://x.com/i/trending/2117377176194699724)

## Devices & accounts

- **Android November bulletin is out (Nov 2): 208 flaws reported by a third-party tracker, including a critical Framework remote-code-execution bug that needs no user interaction.** Google doesn't say any are exploited. **Do:** install the update and check Settings → About phone for a security patch level of 2026-11-05 or later; Pixels get it first, other brands may lag. [Android bulletin](https://source.android.com/docs/security/bulletin/2026/2026-11-01)
- **Google took down the XCPE botnet in 1.3M+ Android TV boxes (MECOOL KM9PRO and others) whose maker, Videostrong, pre-installed a backdoor.** The control servers are gone, but the backdoor is in firmware and reinstalls itself after removal; the boxes were used for ad fraud and as proxies on home connections. **Do:** if you own a cheap no-name or MECOOL Android TV box, unplug it from your network or replace it with a certified device (Google TV Streamer, Apple TV, Nvidia Shield); a factory reset won't help. [Google Cloud blog](https://cloud.google.com/blog/topics/threat-intelligence/shutting-the-door-on-the-xcpe-botnet/) · [BleepingComputer](https://www.bleepingcomputer.com/news/security/google-disrupts-million-device-xcpe-android-malware-botnet-bans-tv-box-maker/)
- **Apple threat notifications hit German officials and staff (around Oct 29)** for suspected zero-click mercenary spyware, and Germany's BSI told recipients to assume compromise. This is targeted at high-profile people, not a mass campaign. **Do:** update iOS to the latest release, and if you're a likely target (journalist, official, large crypto holder) turn on Lockdown Mode and restart the phone regularly. [X story](https://x.com/i/trending/2117283305641091503)
- **Windows NTLM hash-leak bug CVE-2025-24054 got a public GitHub proof of concept (Nov 2).** It lets a crafted file make Windows send a login hash to an attacker. It was patched in 2025 and is on the exploited list. **Do:** make sure Windows is fully updated, and block outbound SMB (TCP 445) to the internet at your firewall or router. [cve.now](https://cve.now/CVE-2025-24054)
