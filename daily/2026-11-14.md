## Servers & dev tools

- **Update: exploit details for PostgreSQL CVE-2026-6460 are now public.** Researcher Mehmet Ince published how he turned this 22-year-old type-confusion bug (CVSS 8.8) into reliable code execution. Any login that can create objects can run code as the database's OS user. cve.now lists a proof of concept on GitHub. No confirmed attacks yet. Several posts on X say C extensions you compiled yourself have to be rebuilt against the new minor release too. **Do:** if you haven't yet, upgrade to **18.7 / 17.12 / 16.16 / 15.20 / 14.25** and restart. Rebuild and reinstall any C extensions you built yourself. Take CREATE rights away from app and shared roles that don't need them. Then do the post-update reindex and full-backup steps from yesterday's release notes. [PostgreSQL advisory](https://www.postgresql.org/support/security/CVE-2026-6460/) · [dbugs write-up summary](https://dbu.gs/news/postgresql-a-22-year-old-data-type-handling-bug-allows-code-execution-on-the-server-20261113) · [X post](https://x.com/ptdbugs/status/2121246087159681347)

- **Rust SSH library russh 0.65.1 fixes two low-severity bugs.** In CVE-2026-128087 (CVSS 3.7), app callbacks such as early data or secondary-channel setup can run before the server's host key is checked, so a malicious server can trigger them. In CVE-2026-128088 (CVSS 2.2), a signature request waiting for confirmation can still finish after the agent is locked. Not known exploited. **Do:** bump `russh` to **0.65.1** (`cargo update -p russh`). [cve.now](https://cve.now/CVE-2026-128087) · [cve.now](https://cve.now/CVE-2026-128088)

- **FrankenPHP: three new CVEs.** The static binaries from 1.8.0 up to (not including) 1.13.2 bundle the vulnerable Brotli 1.2.0 decoder (CVE-2026-128014, the same Brotli bug already on KEV). Versions before 1.13.0 let attackers fake trusted headers such as `X.Forwarded.For` or `X.Authenticated.User` by using dots in the header name (CVE-2026-128023). Docker images before 1.1.11 shipped stale Alpine/OpenSSL libraries (CVE-2026-128027). **Do:** upgrade to **1.13.2** and pull fresh images. Don't rely on proxy-set headers for auth until you've upgraded. [cve.now](https://cve.now/CVE-2026-128023) · [cve.now](https://cve.now/CVE-2026-128014)

- **Minor:** UnrealIRCd labeled-response command injection (CVE-2026-114713) is now on KEV, exploited five days after it was disclosed; upgrade to **6.2.7.1** if you run a linked IRC network. marimo notebook server's unauthenticated terminal RCE (CVE-2026-39987, already on KEV) now has public exploit code; use **0.23.0+** and never expose marimo to the internet. More Rust: Hickory DNS DNSSEC bypasses (CVE-2026-123591/-123595/-123596, all fixed in hickory 0.26.2); `ammonia` XSS when raw-text tags are allowed (RUSTSEC-2026-0533, fixed in 3.3.5 / 4.1.9 / 4.2.5); `ref-swap` use-after-free reachable from safe code (RUSTSEC-2026-0528); `bsv-rs` KVStore signature-check bypass (RUSTSEC-2026-0529). [cve.now](https://cve.now/CVE-2026-114713) · [RustSec](https://rustsec.org/advisories/RUSTSEC-2026-0533.html)

## Devices & accounts

- **Plex Media Server: public scanner templates for two already-exploited bugs.** One lets attackers call other plugins' functions through crafted URLs (CVE-2026-96654). The other lets an admin-level user write arbitrary files (CVE-2026-96656). Both are on CISA KEV, and the new Nuclei templates (ready-made scanner checks) make mass scanning easy. **Do:** update Plex Media Server to **1.43.3.10861 or later**, and don't expose it to the internet without need. [cve.now](https://cve.now/CVE-2026-96654)

- **Expedia confirms a breach through third-party data platform Qubole.** The extortion group n0n claims data on almost a billion travelers (loyalty records, profiles and ~2.5M card details). The size of the leak is not independently verified. **Do:** if you use Expedia, Hotels.com, Vrbo or Orbitz, change the password, turn on 2FA, watch for travel-themed phishing and check card statements. [X story](https://x.com/i/trending/2121339383026692506)

- **SilentAir: a state-level group has been intercepting calls, SMS and SMS 2FA codes on mobile networks in six Asian countries** by abusing telecom signaling (SS7/Diameter), according to Enea. Most victims are in Taiwan. **Do:** move important accounts (email, exchanges, banking) from SMS codes to an authenticator app or a hardware key. [X story](https://x.com/i/trending/2121251460361142604)

- **Telegram widget "RCE":** Pavel Durov says the Android/Windows widget bug needed the user to open a third-party service first, was fixed server-side, and hasn't been used in attacks. **Do:** keep Telegram updated and don't open unknown bots or mini-apps. [X story](https://x.com/i/trending/2121283322039206267)

## Crypto & scams

- **Trust Wallet users on iPhone keep losing USDT on TRON.** Per on-chain data shared on X, at least ~$5.4M has been taken from about 454 wallets, often with small test transfers first. The cause is unconfirmed: Bitquery traces it to a coordinated campaign against iPhone users, while Trust Wallet blames device-level problems such as unpatched iOS or seed phrases stored on the phone. **Do:** if you hold meaningful TRON funds in a Trust Wallet on iPhone, move them to a hardware wallet with a fresh seed. Update iOS and revoke unneeded approvals. Never type your seed phrase into "support" chats. [X story](https://x.com/i/trending/2121251466308628940) · [X post](https://x.com/Praveto_pay/status/2121264014671962126)

- **WhatsApp malware drained a trader after days of watching his machine.** Per X reports, the trader got malware from a throwaway WhatsApp account, and the attackers drained his positions after monitoring him for days, then moved the funds through Hyperliquid and Tornado Cash. **Do:** never open files or "tools" sent by unknown WhatsApp or Telegram contacts on a machine that holds wallets or exchange sessions. [X story](https://x.com/i/trending/2121378001195827497)
