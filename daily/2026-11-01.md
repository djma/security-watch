# Security digest — 2026-11-01
Covers about 24 hours up to 08:00 Asia/Shanghai. Checked CISA's exploited-bugs list (KEV, nothing new since Oct 30), the cve.now feeds and X. No new Chrome or Apple security releases since the Chrome 156 and Apple 27.2 updates already covered.

## Servers & dev tools

- **Update: ClickHouse unauthenticated RCE (CVE-2026-116366, CVSS 9.5) now has public proof-of-concept code on GitHub.** Not on CISA's exploited list yet, but public code makes attacks much easier. **Do:** if you self-host, upgrade today to 26.3.62.3, 26.8.36.3, 26.9.27.3, 26.10.3.7 or later (check with `SELECT version()` on every node, including pinned Docker images), and keep ClickHouse ports off the internet. [cve.now](https://cve.now/CVE-2026-116366) · [X (PoC)](https://x.com/ridvanyagli/status/2116594315581395080)
- **Brotli decoder bug (CVE-2026-111497) is actively exploited and also hits Bun, not just Node.js.** It's on CISA's exploited list (federal deadline Nov 10), and 77 public exploits exist. Any server that decompresses Brotli from untrusted clients is exposed. **Do:** update Bun to 1.4.4 or later, Node.js to 22.23.4, 24.22.1 or 26.12.1, and Python `brotli`/`brotlicffi` to 1.2.1 or later. Check `node -v` / `bun -v` rather than the reported Brotli version, which can still say 1.2.0 when patched. [cve.now](https://cve.now/CVE-2026-111497) · [CCB alert on X](https://x.com/CCBalert/status/2116226271537487876)
- **pgAdmin 4 command execution (CVE-2026-116241, CVSS 9.9).** Any logged-in pgAdmin user, not just admins, can run OS commands on the pgAdmin host through the Import/Export Data tool. No exploitation reported. **Do:** upgrade pgAdmin to 9.19; until then, limit pgAdmin to trusted users and don't expose it publicly. [cve.now](https://cve.now/CVE-2026-116241)
- **russh (Rust SSH library) advisories.** Its agent server ignores the `ssh-add -c` confirm constraint so keys sign without confirmation (CVE-2026-116794, CVSS 8.3), plus several memory-exhaustion bugs (e.g. CVE-2026-116773). Not exploited. **Do:** if a Rust project depends on `russh`, bump it to 0.65 or later (`cargo update -p russh`, then `cargo audit`). [cve.now agent bug](https://cve.now/CVE-2026-116794) · [cve.now EXT_INFO bug](https://cve.now/CVE-2026-116773)
- **Northflank breach: secrets decrypted.** The hosting platform says an attacker decrypted environment variables and used some AI API keys. **Do:** if you deploy on Northflank, rotate every secret, API key and database password stored there, and review the newly enabled audit logs. [X](https://x.com/i/trending/2116365554244108506)

## Devices, accounts & scams

- **Real Google security emails used for phishing.** Scammers put fake invoice text (e.g. a "$399 McAfee" charge) into app-password names on throwaway accounts, so Google sends a genuine, fully authenticated alert that pushes you to call a scam number. YouTube creators report losing channels. **Do:** never call a number from an account alert; check activity only by going to myaccount.google.com yourself. [X](https://x.com/i/trending/2116601284442591433)
- **DeFi sites DNS-hijacked to drain wallets.** About a dozen sites (including flap.sh and kintsu.xyz, all registered via Name.com) redirected visitors to a wallet drainer; about $138K stolen so far. **Do:** don't connect a wallet to sites that suddenly ask for new approvals, and if you connected to these on Oct 31, revoke approvals at revoke.cash. [X](https://x.com/i/trending/2116359578120274100)
