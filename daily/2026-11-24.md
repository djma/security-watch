## Servers & dev tools

- **pgjdbc (PostgreSQL JDBC driver): six CVEs, fixed in 42.7.15.** The worst (CVE-2026-134841, 8.1) lets correctly quoted text run as SQL when it sits inside a JDBC escape like `{ts ...}`, a dollar quote with an unusual tag, or an `E''` string. Others: TLS not enforced for some settings (CVE-2026-134845), NUL startup-parameter injection (CVE-2026-134848), GSS-encryption reply replay (CVE-2026-134846), code execution through unqualified catalog queries for a low-privilege DB user (CVE-2026-134844), and SQL injection after a desynced connection (CVE-2026-134843). Not known exploited. **Do:** move Java apps to **org.postgresql:postgresql 42.7.15** (as of Nov 23 cve.now said Maven didn't have it yet, so check again). Until then, keep app DB roles low-privilege and use `sslmode=verify-full`. [cve.now](https://cve.now/CVE-2026-134841) · [X: @cvedotnow](https://x.com/cvedotnow/status/2124921525081960602)
- **Update: MONAI Label CVE-2026-133968 (the Cairn AI-agent zero-day) went on CISA KEV Nov 23.** **Do:** upgrade to **0.8.6** and keep it off the internet. [X: @cvedotnow](https://x.com/cvedotnow/status/2124969338260099459)
- **Minor (not known exploited):**
  - **Rust `url` RUSTSEC-2026-0592:** `Url::origin()` on a deeply nested `blob:` URL overflows the stack and aborts the process. That's a remote crash if you call it on untrusted input. Fix: **url 2.5.9** (`cargo update -p url`). [RustSec](https://github.com/rustsec/advisory-db/blob/main/crates/url/RUSTSEC-2026-0592.md)
  - **Rust `cookie` RUSTSEC-2026-0594:** private (encrypted) cookie nonces can repeat after `fork()`, which breaks AES-GCM. This only applies to apps that fork worker processes themselves. Rocket and normally-run axum are not affected. Fix: **cookie 0.18.3**. [RustSec](https://github.com/rustsec/advisory-db/blob/main/crates/cookie/RUSTSEC-2026-0594.md)
  - **Rust `parquet` CVE-2026-125651 (RUSTSEC-2026-0595):** encrypted Parquet files written with Bloom filters keep the Bloom filter data in plaintext. Rewrite such files with Bloom filters off. [cve.now](https://cve.now/CVE-2026-125651)
  - **Linux "NoisyTCP" CVE-2026-99288 (7.5):** crafted TCP traffic can crash a server remotely when SYN cookies kick in. There are now 5 public PoC repos. Fixed in kernels **6.12.117 / 6.18.63 / 7.3.4**, so install your distro's kernel update and reboot. [cve.now](https://cve.now/CVE-2026-99288)
  - **OpenSSH "SSHole" CVE-2026-123158 (on KEV since Nov 9):** a public write-up now reproduces the auth bypass on Alpine/musl with a 257-byte password. If you run Alpine with SSH password login, update to **OpenSSH 10.6p2** or switch to key-only. [X: r/netsec](https://x.com/_r_netsec/status/2124874511074070960)
  - **AutoGPT CVE-2026-130169 (10.0):** a hard-coded default JWT secret lets anyone forge admin logins. If you self-host it, update and set your own secret. [X: @cvedotnow](https://x.com/cvedotnow/status/2125004566127141274)
  - **GitHub release hijack:** someone used the owner's credentials to push tags to james-6-23/codex2api, and its release workflow built backdoored binaries. If you installed a recent release, reinstall from a verified build and rotate any keys it could read. [X: @blackorbird](https://x.com/blackorbird/status/2124837645864116355)

## Devices & accounts

- **GL.iNet routers and KVMs: attackers abused the GoodCloud remote-management service to install malware (Nov 20, notice updated Nov 23).** GL.iNet blocked the attack path and released security firmware that removes the known malware. CVE IDs are pending. **Do:** install the latest stable firmware for your exact model. If the device was ever connected to GoodCloud, also change every password and key stored on or reachable from it (VPN keys, Wi-Fi, admin). If you suspect a compromise, reinstall *without* keeping settings and don't restore old backups. For a KVM, also check the attached computer. [GL.iNet notice](https://www.gl-inet.com/blogs/blog/glinet-security-notice-2026-11-20) · [BleepingComputer](https://www.bleepingcomputer.com/news/security/hackers-exploit-glinet-cloud-flaw-to-infect-routers-kvm-devices/)
- **MoldyRoost: ads that hack older iPhones as soon as the page loads, to steal wallet seed phrases, keychain data and messages.** Confiant tied 480+ ad domains (May 12 to Nov 17, 47+ countries) to the Coruna, DarkSword, SilkPath and GhostWave exploit kits. Coruna covers iOS 13 to 17.2.1, DarkSword iOS 18.4 to 18.7, and there is code aimed at iOS 26.3. The implant searches Notes for seed phrases, decodes QR codes in saved photos, and hooks MetaMask, Phantom and Trust Wallet. **Do:** update to **iOS 27.2.1 or 26.7.3** (18.7.12 on XS/XR). Turn on Lockdown Mode on any iPhone you can't update. Never keep seed phrases in Notes or photos. [Confiant](https://blog.confiant.com/p/moldyroost-a-malvertising-machine) · [CoinDesk](https://www.coindesk.com/tech/2026/11/23/moldyroost-malvertizing-campaign-uses-one-tap-iphone-hacks-to-hunt-crypto-wallet-keys-research-shows)
- **Chrome 158.0.8127.88/.89 (desktop) fixes one critical bug, CVE-2026-134401 in Variations.** Not reported exploited. Android is on 158.0.8127.92 and Extended Stable on 156.0.8078.114. **Do:** relaunch Chrome. [Chrome Releases](https://chromereleases.googleblog.com/)
- **Synology DSM CVE-2026-120382 (9.8):** an unauthenticated attacker can read or write any file through the OAuth API. Not known exploited. **Do:** update DSM to **7.4.1-90080-2 / 7.3.2-86009-6 / 7.2.2-72806-11 / 7.2.1-69057-14 / 7.1.1-42962-10** and don't expose DSM to the internet. [Synology SA-26:21](https://www.synology.com/en-global/security/advisory/Synology_SA_26_21) · [cve.now](https://cve.now/CVE-2026-120382)
- **Cleverbridge breach: card numbers, expiry dates and CVVs stolen.** Cleverbridge runs checkout for many software vendors (it lists Parallels, Sony, Red Hat, SUSE and others) and began notifying customers Nov 20. **Do:** if you bought software through a Cleverbridge checkout this year, watch your statements, and replace the card if you get a notice. [BleepingComputer](https://www.bleepingcomputer.com/news/security/cleverbridge-warns-hackers-stole-credit-card-numbers-cvvs-in-data-breach/)

## Crypto & scams

- **~$600K drained from a Trezor Safe 7 (via an iPhone 17, Bluetooth) plus an Exodus wallet, Nov 21. The cause is unconfirmed.** The TRON transfer was signed with the wallet's own owner authority. The victim says the seed only ever existed on paper. Trezor says it has no reports of remote drains and points to a leaked backup. **Do:** keep the phone updated, check the full transaction on the device screen before you confirm, and move large holdings to a fresh seed if your backup was ever photographed or typed. [crypto.news](https://crypto.news/trezor-exodus-user-reports-600k-crypto-theft/)
- **Pump.fun ends external-wallet sign-in on the web Nov 30 (15:00 UTC) and asks users to paste a private key to keep their account.** This is a gift to phishers. **Do:** don't paste a private key into any site or "migration" DM. If you have funds there, make a new account and transfer them instead. [Pump docs](https://pump.fun/docs/wallet-login-changes) · [The Block](https://www.theblock.co/news/ecosystems/2026-11-23-pump-fun-draws-criticism-over-private-key-imports-as-it-retires-external-wallet-sign-in-on-web-444926)
- **"Wallet check" / airdrop-eligibility drainers and hacked Discord accounts are spreading.** Compromised Discord accounts send friends "Minecraft SMP" mods (.jar files) that steal tokens and browser passwords. **Do:** don't sign approvals on airdrop-checker sites, revoke stale approvals, and never run a modpack or .jar sent in a DM. [NewsMinecraft](https://newsminecraft.com/minecraft-smp-scam-hits-creator-discords-again/)
- **WazirX and ZebPay user contact data exposed through the vendor MoEngage.** Emails, contact identifiers and device data were exposed, but no passwords or keys. Expect targeted phishing that uses these brands. [Outlook Money](https://www.outlookmoney.com/invest/wazirx-zebpay-users-data-exposed-in-moengage-breach-both-say-funds-safe)
