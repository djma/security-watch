## Servers & dev tools

- **OpenSSH CVE-2026-123158 (sshole): Metasploit module published Nov 26.** This is a password-authentication bypass in `sshd` before **10.6p2**. It only affects Linux builds on musl libc with PAM turned off (Alpine is the usual case). It was already on CISA KEV (added Nov 9), and 54 GitHub PoC repos are now tracked, so expect scanning to pick up. **Do:** update to **OpenSSH 10.6p2** or your distro's fixed package on every Alpine/musl host and container that runs sshd. Until then, set `PasswordAuthentication no` and use keys only. [cve.now](https://cve.now/CVE-2026-123158) · [OpenSSH release notes](https://www.openssh.com/releasenotes.html)
- **Drupal core SA-CORE-2026-019 / CVE-2026-136716: exploited, "highly critical".** The Nov 18 installer fix (SA-CORE-2026-017) didn't cover sites left in odd or incomplete install states, and those sites can still be taken over. Drupal says this is being exploited in the wild. **Do:** update to **10.6.23 / 11.3.23 / 11.4.14** and block access to `install.php`. Check that the user 1 email is one you control, reset user 1's password, and look through logs for changes to user 1. [Drupal advisory](https://www.drupal.org/sa-core-2026-019)
- **PolinRider: 7,600+ GitHub repos (2,330 accounts) poisoned by North Korea-linked attackers.** The attackers slip a small Python/Node loader into legitimate-looking commits, and it pulls its C2 address from Ethereum transactions. Opening an infected project in VS Code can be enough to run it. It steals credentials, browser data and crypto wallets, and also spreads through fake job tests. **Do:** open unfamiliar repos (job tasks, forks, "fix this bug" requests) in VS Code Restricted Mode or a throwaway VM. Don't let workspace tasks run automatically. Check recent commits in repos you depend on for odd utility files. [X: The Hacker News](https://x.com/TheHackersNews/status/2125971810642743361) · [X: DFIR Radar (Apiiro/SafeDep)](https://x.com/DFIR_Radar/status/2125999265621369296)
- **Coder CVE-2026-137547 (9.2): database password leak.** If the database connection fails, an unauthenticated request with a junk API key gets back the temporary AWS IAM PostgreSQL password, which works for about 15 minutes. **Do:** update to **2.39.1 / 2.38.7 / 2.37.11 / 2.34.19 / 2.29.27**. [cve.now](https://cve.now/CVE-2026-137547) · [X: @cvedotnow](https://x.com/cvedotnow/status/2126021267937464707)
- **@fastify/express CVE-2026-135279 (9.1): auth middleware skipped.** An empty route parameter bypasses middleware mounted inside an Express Router or sub-app passed to `fastify.use()`. **Do:** update to **4.0.14**. [GitHub advisory](https://github.com/fastify/fastify-express/security/advisories/GHSA-f9qf-hfc5-7xpj)
- **llama.cpp CVE-2026-137567 (9.3): unauthenticated heap write in the ggml RPC server** (builds b11450 up to b12658). **Do:** update to **b12658 or later**, and never expose `rpc-server` beyond localhost or a trusted network. [VulnCheck](https://www.vulncheck.com/advisories/llama-cpp-b11450-before-b12658-out-of-bounds-write-via-rpc-copy-tensor)
- **Malicious npm packages flagged Nov 26:** `tzero-mcp` (12.3.0), `safeclamp`, and AI-coding-themed `ali-ai-coding-trace` (runs a remote script at install) and `toga-ai`. **Do:** search your lockfiles. If one was installed, remove it and rotate every secret on that machine or CI runner. [X: infrastack (tzero-mcp)](https://x.com/infrastack_ai/status/2126015171172917544) · [X: infrastack (safeclamp)](https://x.com/infrastack_ai/status/2125983729395122610) · [X: Faseel](https://x.com/Faseel_infosec/status/2126005804113314153)

## Devices & accounts

- **SYS01 infostealer spread through Meta (Facebook/Instagram) ads.** It poses as wallpaper apps (Wallpaper Engine / Lively Wallpapers), then uses browser management policies to force-install an extension (posing as "Docs Helper" / "Document Hub"). The extension steals session cookies and reads Gmail and Outlook. **Do:** check `chrome://policy`, `edge://policy` and Firefox `about:policies` for policies you didn't set, and remove any extension you didn't install. If you find one, sign out all Gmail/Outlook sessions and change those passwords. [cve.now (BleepingComputer/Bitdefender)](https://cve.now/SZB-34599e7b6c) · [X: @cvedotnow](https://x.com/cvedotnow/status/2125920803900346851)
- **Bitcoin Core wallet privacy flaw.** An attacker sends a cheap dust payment to your address and watches which node rebroadcasts it. That links the address to your node's IP; it worked 30/30 times in tests, at under $0.35 each. It affects hot wallets, watch-only setups, and Sparrow / Electrum Personal Server backends. A fix is still being discussed. **Do:** if address-to-IP privacy matters to you, run your node Tor-only, and don't treat a home node's IP as private. [X: Cointelegraph](https://x.com/Cointelegraph/status/2126026172777775463)
- **Home routers with public exploits and no fix listed:** D-Link R32 1.10B02, unauthenticated command injection (CVE-2026-136823, 10.0), and TOTOLINK N350RT, auth bypass (CVE-2026-137043). **Do:** turn off remote/WAN management. If you own one of these, plan to replace it. [X: @cvedotnow (D-Link)](https://x.com/cvedotnow/status/2125792257861140652) · [X: @cvedotnow (TOTOLINK)](https://x.com/cvedotnow/status/2125789743338131502)
- **Zcash:** developers are asking users to move funds out of the 2018 Sapling pool into Ironwood because of aging pairing-based cryptography. The risk is theoretical, not an active exploit. Move funds through your own wallet only, and ignore DMs offering "migration help".
- **Chrome 159** is rolling out as an early stable release (159.0.8154.33/.34 desktop, .33 Android) with no security notes yet. Stay on 158.0.8127.88 or later until it reaches you. [Chrome Releases](https://chromereleases.googleblog.com/)

## Scams

- **"Sneaky 2FA" phishing kit steals session cookies after you finish MFA**, so the attacker gets in without a second MFA check. Barracuda says it targets financial-services and insurance users. Use passkeys or hardware keys where you can, and sign out all sessions if you entered credentials on a lookalike page. [X: BadgerSignal (Barracuda)](https://x.com/BadgerSignalHQ/status/2125814653704142930)
- **Fake Sedgwick claim-update emails** route every link through a real Smartsheet form, so they get past filters. [X: KnowBe4 ThreatLabs](https://x.com/Kb4Threatlabs/status/2125870805741674851)
- **EasyEquities** (South African broker, 1.3M investors) has restricted logins after a security incident and says client funds are safe. Users should expect phishing that uses the incident as a lure.
