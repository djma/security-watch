# Security digest — 2026-11-11
Covers about 24–36 hours up to 08:00 Asia/Shanghai. Checked the cve.now feeds (exploited, critical, Redis/PostgreSQL, Rust crates), CISA's exploited-bugs list (KEV), Chrome, Microsoft and Node.js release notes, the PostgreSQL release schedule, vendor advisories and X. Most urgent today: an exploited Chrome zero-day and an exploited Outlook bug from Patch Tuesday. Nothing new for ClickHouse, Redis or Bun beyond earlier digests.

## Servers & dev tools

- **PostgreSQL minor releases are due tomorrow, Thu Nov 12, with security fixes.** Commits tagged CVE-2026-6460 (unsafe tuple "deforming" and type-confusion fixes) landed Nov 9, back-patched to 14; details come with the release. Nov 12 is also the last update for PostgreSQL 14. No known exploitation. **Do:** schedule the minor upgrade on all supported branches as soon as packages appear, and plan a move off 14. [PostgreSQL release schedule](https://www.postgresql.org/developer/roadmap/) · [commit note on X](https://x.com/nori_shinoda/status/2119945398068654386)

- **React Server Components: unauthenticated RCE now rated critical (CVE-2026-126187, CVSS 9.5).** Affects `react-server-dom-webpack`, `-parcel` and `-turbopack` 19.0.0–19.0.8, 19.1.0–19.1.9, 19.2.0–19.2.8 and 19.3.0 in server setups (RSC frameworks/bundlers, whether run on Node or Bun); only rare payload shapes trigger it. Not known exploited; no public exploit tracked. **Do:** check lockfiles for those packages and upgrade to **19.0.9, 19.1.10, 19.2.9 or 19.3.1**, then redeploy. [React advisory](https://github.com/react/react/security/advisories/GHSA-xqc2-xf4c-x3h3) · [cve.now](https://cve.now/CVE-2026-126187) · [cve.now on X](https://x.com/cvedotnow/status/2120289292685549820)

- **Node.js security releases (HIGH) for 22.x, 24.x and 26.x are due today, Nov 11.** Issue details and version numbers ship with the release. **Do:** update Node hosts and rebuild Node-based container images once the releases are out; end-of-life lines (20.x, 25.x and older) get no fix. [Node.js announcement](https://nodejs.org/en/blog/vulnerability/november-2026-security-releases)

- **Nine malicious crates pulled from crates.io (RUSTSEC-2026-0464 to -0472).** Names: `electrumd`, `shinchina`, `shinchina-test`, `gabby-types-sec`, `env-test-guard`, `top_level_crate`, `build_dep`, `webhook_commands`, `sec-gemini`. RustSec says `electrumd` tried to send build-environment data to an outside URL, with no evidence it was actually used. **Do:** `grep` your `Cargo.lock` files for these names and run `cargo audit`; if any appear, rebuild that machine or CI runner and rotate the secrets it could see. [RustSec on cve.now](https://cve.now/RUSTSEC-2026-0465)

- **Update: two more Hickory DNS CVEs, same fix.** CVE-2026-123604 (resolver retry loop DoS from truncated responses) and CVE-2026-123585 (query amplification via irrelevant CNAMEs) are both fixed in **hickory 0.26.2**, the version from the Nov 9 digest. **Do:** if you haven't, `cargo update -p hickory-resolver -p hickory-proto`. [cve.now](https://cve.now/CVE-2026-123604)

- **MongoDB: batch of fixes including a pre-auth use-after-free in replica sets (CVE-2026-118383, CVSS 9.5).** Replica-set members (not standalone `mongod`) can crash or, under some conditions, run attacker code; others include a certificate-validation bypass in the macOS TLS client (CVE-2026-120808). Not known exploited. **Do:** upgrade to **9.0.7, 8.3.16, 8.0.37, 7.0.48, 6.0.30, 5.0.35 or 4.4.32**, and keep MongoDB off the public internet. [cve.now](https://cve.now/CVE-2026-118383) · [cve.now on X](https://x.com/cvedotnow/status/2120272686647505321)

- **Reminder: CISA's deadline for OpenSSH *sshole (CVE-2026-123158) is Thu Nov 12.** Exploitation continues against musl builds without PAM (Alpine, slim containers). **Do:** OpenSSH **10.6p2** or your distro's fixed package, restart sshd, `PasswordAuthentication no`. [cve.now](https://cve.now/CVE-2026-123158)

## Devices & accounts

- **Chrome zero-day exploited in the wild: CVE-2026-125350 (use-after-free in XML), added to CISA KEV Nov 10.** Reports call it the year's eighth exploited Chrome zero-day. The same update fixes CVE-2026-125347, a FileSystem bug that can lead to code outside the sandbox with some user interaction. **Do:** update Chrome to **157.0.8103.50/.51** or later (Help > About Google Chrome) and relaunch; update Edge, Brave and other Chromium browsers as their fixes land. [Chrome release notes](https://chromereleases.googleblog.com/2026/11/stable-channel-update-for-desktop_018223192.html) · [cve.now](https://cve.now/CVE-2026-125350) · [X story](https://x.com/i/trending/2120079251236118563)

- **Microsoft Patch Tuesday (Nov 10): exploited Outlook spoofing bug CVE-2026-124194 is on CISA KEV.** The release is very large (over 1,000 fixes across Windows and Office). **Do:** run Windows Update and update Office/Outlook (LTSC 2021 to 16.0.14334.21048, LTSC 2024 to 16.0.17932.21140, Microsoft 365 via its normal update channel), then restart. [Microsoft advisory](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-124194) · [cve.now](https://cve.now/CVE-2026-124194) · [X story](https://x.com/i/trending/2120255078225592453)

- **Dev/AI platform breach disclosures: Railway and Fireworks AI.** Railway's postmortem says an Oct 20 build-system breach could expose environment variables in up to 1.85% of workspaces, with AI provider keys targeted; Fireworks AI expanded its October breach to include billing data and some credentials. **Do:** if you use either, rotate env secrets and AI/API keys stored there, and check provider usage dashboards for unexpected spend. [Railway on X](https://x.com/i/trending/2120196359563387358) · [Fireworks on X](https://x.com/i/trending/2119903293426024706)

## Crypto & scams

- **Across Protocol's domain was hijacked via social engineering at its registrar (Namecheap) on Nov 10, ~18:45 UTC (Nov 11, ~02:45 Asia/Shanghai).** The fake site drained connected wallets; Across says contracts and APIs were not affected and affected users will be made whole. **Do:** don't use the Across app until it posts an all-clear; if you connected a wallet there on Nov 10, revoke approvals at revoke.cash and contact Across only via its official account. Good moment to enable registrar lock and 2FA on any domains you own. [Across on X](https://x.com/AcrossProtocol/status/2120278803318489362)

- **Initia halted its chain after a ~$605K theft via compromised rollup keys (Nov 10).** **Do:** avoid bridging to or from Initia until it's back up and the team posts an all-clear. [X story](https://x.com/i/trending/2120071344134209588)

- **Discord "someone reported all your friends" scam is back.** Hacked friend accounts send fake screenshots and push you to add a "support" account, which then asks for payments or logins. **Do:** Discord support never DMs you; verify through another channel and ignore. [X story](https://x.com/i/trending/2120219410900074885)
